# IELTS 机考模拟器 — 综合优化提示词 v2

> 使用方法：把下面整段内容复制，粘贴给 AI 编程助手（Cursor / Copilot / Claude 等），让它在你的项目代码上逐项实现。
> Logo 图标四个文件在 `~/workspace/` 目录下（`yandi-ventures-icon*.png`），先复制进项目再引用。
> 起始动画演示页为 `yandi-splash-demo.html`，动画代码直接从里面搬。

---

## 项目背景

- 纯前端静态网站（HTML / CSS / JS），无后端、无登录、无账号体系
- 所有用户数据保存在浏览器 localStorage
- 四个模块：
- **阅读 Reading**：剑桥雅思 17 Test 1–4，每套 3 篇文章 40 道题，60 分钟倒计时
- **写作 Writing**：Task 1（20 分钟）/ Task 2（40 分钟）切换，随机抽题，作答区实时字数统计，草稿自动保存
- **单词 Vocabulary**：词库导入/示例/导出/清空，四选一 + 翻卡自测，错词本、复习队列、学习统计
- **范文 Essays**：24 篇范文（Task 1 / Task 2 各 12 篇），搜索、筛选、排序、收藏、对照阅读
- 界面语言为中文，现有文案风格保持不变

## 第一部分：Bug 修复（经回归测试确认仍未修复，优先处理）

### BUG-1全站"清空"类按钮失效

**现象**：以下按钮点击后均无任何反应，也没有确认弹窗——
写作模块"清空"、单词模块"清空词库"、阅读交卷面板"清空本套作答"、**顶栏新增的"清空所有本地数据"**。

**判断**：四个按钮同时失效，极大概率是共用的清空逻辑或事件绑定出了问题，请先检查公共代码。

**要求**：
1. 修复共用逻辑，让所有清空按钮恢复工作；
2. 所有清空操作必须先弹二次确认框（文案："确定要清空吗？此操作不可恢复。"），点确认后才执行；
3. 执行后清空对应数据并刷新 UI（作答区、字数统计、题号高亮、已答计数等同步更新）。

### BUG-2 阅读"重置"按钮行为不符合预期

**现象**：点击"重置"只把计时器归零到 60:00，答案、题号高亮、已答计数全部保留，且无确认框。

**要求**：点击"重置"弹出确认框，确认后同时重置计时器 **和** 清空本套所有答案（含填空文本、选项选择、题号高亮、已答计数）。

### BUG-3 Test 4 Q1–6 题型标签错误

**现象**：Q1–6 是 TRUE/FALSE/NOT GIVEN 判断题，题型标签却显示"填空"（Test 1 中同类题型标签为"判断"）。

**要求**：把 Test 4 Q1–6 的题型标签改为"判断"，与 Test 1 保持一致。

### BUG-4 文章标题缺失 / 截断

**现象**：
- Test 2 Passage 3：主标题只显示 "Reading Passage 3"，真实标题 "Insight or evolution?" 被降级为副标题/正文；
- Test 3 Passage 2：主标题只显示 "Reading Passage 2"，无真实标题；
- Test 3 Passage 3：标题截断为 "Building the Skyline: The Birth and Growth of Manhattan's"（缺后半）；
- Test 4 Passage 2：主标题只显示 "Reading Passage 2"，"Does education fuel economic growth?" 为副标题/正文。

**要求**：所有文章主标题显示真实完整标题，副标题样式的问题一并修正。

### BUG-6 交卷后未锁定答案 + 交卷无确认

**现象**：交卷后答题输入仍可修改；"已交卷"面板在切换题源再回来后消失；点击交卷直接提交，没有确认框。

**要求**：
1. 点击交卷先弹确认框（"确定要交卷吗？剩余 X 题未作答。"）；
2. 交卷后锁定本套所有答题输入（disabled），明确显示"已交卷"状态；
3. 提供"重新作答"按钮，点击经二次确认后解锁并清空本套答案；
4. 交卷状态按题源（Test 1–4）独立保存，切换回来后状态不丢失。

### BUG-7 单词模块首次进入残留旧数据

**现象**：新访客首次进入单词模块就已经有 50 个示例词和做题记录（开发调试时的 localStorage 残留），且"清空所有本地数据"入口是死的，清不掉。

**要求**（依赖 BUG-1 修复）：
1. 区分"示例数据"和"用户数据"，首次访问默认不加载示例；
2. 词库为空时显示空状态 + 引导按钮"载入示例词表（50 词）"。

### BUG-8 半成品功能收尾

**现象**：
- "待检查"标记：图例和"待检查 0"按钮已存在，但题号格 hover 不出星标，点击/双击只能跳转，标记功能实际不可用；
- 划词高亮：页面上有"选中文文本可高亮"的提示文字，但阅读区无中文文本、选中英文也无工具条，功能缺失。

**要求**：二选一——要么把两个功能真正做完（见第二部分 P2-1、P2-2），要么删掉页面上的相关提示文字，不要留"说了但做不到"的文案。

## 第三部分：新增优化（性能 / PWA / 数据安全 / 分享 / 无障碍）

### P0 数据导出与导入（本轮最高优先级）

**背景**：所有数据只在 localStorage，清浏览器缓存就全没了；功能越做越多，用户数据越值钱。

**要求**：
1. 设置区（或页眉"数据保存在本机"徽章旁）加"导出全部数据"按钮，导出 JSON 文件，文件名带日期如 `ielts-backup-2026-10-18.json`；
2. 加"导入数据"按钮，选择 JSON 文件后二次确认再覆盖写入，导入前校验文件格式，格式不对要报错提示；
3. 导出内容包括：各题源作答记录、写作草稿与历史、词库、学习统计、错词本、收藏。

### P1 PWA：可安装、离线可用

1. 加 `manifest.json`（name、icons 用 192/512 图标、display: standalone、theme_color）；
2. 加 service worker 缓存静态资源与题库数据，实现离线打开、离线做题；
3. iOS"添加到主屏幕"用 180px 图标（见第四部分）。

### P1 性能

1. 范文模块：列表只渲染卡片，点进详情再加载全文；所有图片加懒加载（loading="lazy"）；
2. localStorage 读写加防抖：作答输入时不要每次敲字全量写，停顿 0.5 秒后再写。

### P2 分享与 SEO

1. 补 `<title>`、meta description、Open Graph 标签（og:title / og:description / og:image），微信分享出去有正常卡片；
2. 页眉或页脚加"复制分享链接"按钮。

### P2 键盘与无障碍

1. 阅读做题支持键盘：填空题 Tab 顺序切换、选择题方向键移动 + 回车确认；
2. 计时器、题号格加 ARIA 标签；
3. 错题本 / 范文加 `@media print` 打印样式；
4. 已有 `prefers-reduced-motion` 处理的地方保持，没有的动画补上。

## 第五部分：起始动画（Splash）

动画代码见 `yandi-splash-demo.html`（演示页，可直接在浏览器打开看效果）。

**集成要求**：
1. splash 层全屏 fixed 定位，z-index 最高，盖在所有内容之上；
2. 页面加载即播放，总时长约 3.4 秒后自动淡出（opacity + scale 过渡 0.65s），结束后 `display:none`，不能遮挡主界面交互；
3. 点击任意处 / 右下角"跳过"可提前结束；
4. 兼容 `prefers-reduced-motion`：用户设置了减少动态效果时，只显示静态 logo 0.6 秒后直接淡出；
5. logo 用 `assets/yandi-ventures-icon.png`（512 版），不要用 base64 内嵌大图；
6. 动画内容：深色底 + 金色粒子上升 → logo 缩放登场（金色光晕呼吸）→ 双旋转光环 → "雅思机考备考"逐字浮现 → "IELTS · CBT SIMULATOR" → 金色进度线 → 淡出；
7. 每次打开网站播放一次即可。

## 全局约束（必须遵守）

1. 不引入后端、不引入登录，所有数据继续走 localStorage；
2. 不破坏现有正常功能：计时器、作答流程、单词测试流程、范文浏览、主题/字号切换；
3. 保持现有中文界面文案风格；
4. 移动端窄屏：左右分栏布局在窄屏下改为上下堆叠，确保手机可用；
5. 每个修改点完成后自测一遍相关按钮，确认无报错、无回归；
6. **不要只做视觉不做功能**：上一轮出现过"加了入口但按钮是死的"的情况，所有新增按钮必须真实可用。
