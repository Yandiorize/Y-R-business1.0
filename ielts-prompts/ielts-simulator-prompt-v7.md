## 第 0 部分：本版最高优先级 — 上一版实测未落地的两项（先做这两项，再做其他）

实测证据（用户 2026-10-21 iPad 实拍，练习页第 1 / 30 题）：题目“negative adj”里词性 adj 与单词 negative 仍然是同一个字号；页面下半部分仍然大片空白。

### 0-1 词性字号：必须先查结构，再改样式（根因级）

1. 先检查题目区单词与词性的渲染方式：如果单词与词性现在是同一个文本节点 / 同一个 class（例如直接拼成 "negative adj" 一段文字），只改 CSS 永远分不开——必须先把它们拆成两个独立元素：单词一个 span、词性一个 span，各自独立 class；
2. 拆开后分别定样式：单词大字号加粗，词性用约 55%–65% 的字号、颜色弱化、与单词基线对齐；
3. 词库列表行如果也是单词与词性同字号并排，同步按同样规则改；
4. 验收实例：题目“negative adj”里的 adj 必须肉眼可见地明显小于 negative；只报“已改小”不算数，必须报拆分后的两个元素类名。

### 0-2 练习页下方空白：必须改布局结构，不是加内边距

1. 先检查练习页内容容器是不是固定高度 / 绝对定位 / 顶部对齐导致内容顶置：是的话，改为 flex 垂直居中或内容区高度 100dvh 内分布；
2. 单词字号放大，选项卡片加高、间距加大；答题后在题目下方出现反馈卡片：中文释义 + 例句 + “再听一遍”按钮（例句只在答后出现，答前不剧透）；底部保留一排小统计：本轮已答 x / y、正确率；
3. 验收：题目与选项在视口内垂直居中、上下留白均匀，不许上半截满、下半截空。

### 0-3 防“假落地”规则（本版所有项通用，违反即为未完成）

1. 每一项汇报时必须写明：改了哪个文件 + 关键改动（类名 / 函数名 / 改动前后对比），只写“已完成 / 已修复”不算数；
2. 发布后必须用无痕窗口 / 新标签重新打开验证一遍，排除旧缓存假象；汇报里写明验证方式；
3. 发布时更新静态资源指纹或 service worker 缓存版本，确保用户刷新后拿到的是新版，不是缓存的旧版；
4. 如果某项因结构原因确实做不了，必须明说原因和替代方案，不许报“已完成”。

## A 部分：顶栏三处

### A-1 三个图标按钮换种样式（不要再修圆圈）

- 背景：顶栏三个细线圆圈图标按钮反复修不好（先是椭圆，后是细线淡圈、图标小而难认），不再继续修圆圈。
- 改为“图标 + 文字”的小胶囊按钮，三个分别是：🗑 清空、A 字号、🌙/☀️ 主题（文字写“主题”二字，不要只留图标让人猜）。
- 三个按钮统一样式、同高、同间距；图标与文字同色、对比度足够，深色下清晰、浅色下也清晰；按钮宽度由内容（图标 + 文字）自然决定，不许再出现椭圆、细线淡圈、图标过小；空间不足时标题文字省略号截断，不挤压按钮。
- 顶栏品牌 Y-IELTS、logo 图标不动。

### A-2 计时器取消“框里套框”

- 现状：阅读工具条是一个大圆角框，里面的计时器（60:00 + 进度条）又单独套了一个小圆角框，双层嵌套看着不自然。
- 改法：取消计时器内层的圆角边框——时间数字与进度条直接落在工具条上，只保留工具条外层一层框；交卷按钮保持独立按钮，不再被第二层框套住；进度条与时间数字的对齐、颜色、计时功能全部不变。

### A-3 图标位置校准（几何验收标准）

- 按钮内图标几何居中：图标中心与按钮中心重合，水平与垂直偏差均 ≤1px；图标不得被裁切、不得偏上 / 偏下 / 偏左 / 偏右；
- logo 图标与 Y-IELTS 品牌文字垂直居中对齐、基线一致；品牌文字不得被图标顶起或压下；
- 单词行喇叭图标、练习页题目旁喇叭图标、底部标签栏图标与各自文字垂直居中对齐；
- 图标与文字组合时（如 A-1 的胶囊按钮），图标与文字在同一基线上，图标不得高于或低于文字半行以上；
- 图标大小统一：同一组图标用同一尺寸，不得一个大一个小。
- 验收方法：用元素包围盒实测中心点坐标逐个核对（不要只凭截图目测），桌面与手机各一遍；发现任一图标偏差 >1px 即为未通过。

## B 部分：阅读界面 — 扩充到几乎全屏 + 整体清晰度

### B-1 扩充到几乎全屏（验收重点：iPad 横屏与桌面宽屏）

1. 内容容器放宽：左右边距缩小到 12–16px，容器宽度改为 96vw 以上；超宽屏可设 1600px 上限防止行过长，但 iPad 与普通桌面必须接近全屏；
2. 高度顶满：文章与题目两栏的高度 = 视口高度 − 顶栏 − 工具条 − 页脚，基本占满剩余空间，底部不再留大片空白；页脚跟在内容末尾，不单独占空间；
3. 两栏比例维持现状（文章稍宽），栏内滚动方式不变；圆角、间距、主题色不变；
4. 手机（≤430px）布局不动（已是全宽堆叠），桌面窄屏不变。

### B-2 整体清晰度提升（发雾、发灰问题）

1. 内容卡片去雾化：卡片背景改用实色或不透明度 0.92 以上；取消或大幅降低内容区的 backdrop 模糊（模糊只允许留在顶栏等装饰层）；
2. 文字对比度：正文用纯色（浅色下近黑、深色下近白），次级文字、题号、提示小字同步加深/提亮到清晰可读；不许文字直接压在渐变背景上；
3. 取消多层半透明叠加：同一区域不许两层以上半透明玻璃叠加，避免灰雾感；
4. 保留液态玻璃的圆角与细边框观感，但清晰优先：宁可牺牲一点玻璃感，也要正文锐利。

## C 部分：单词练习页其他项（声音是前提，先修声音再做自动读）

### C-1 修声音：完全没声（禁令：禁止静默跳过）

按以下顺序排查并修复（speechSynthesis 方案，不接任何付费语音 API）：

1. 语音解锁必须发生在用户手势里：点“开始本轮”时，先调用 speechSynthesis.getVoices() 并播一句极短测试音（或 cancel + resume）完成解锁；之后每题的朗读复用已解锁的语音通道，不许在非手势回调里从零初始化；
2. 语音列表是异步加载的：监听 voiceschanged 事件，等列表就绪后再 speak；首次列表为空时延迟重试（如 3 次 × 300ms），仍为空要在页面上明确提示“当前设备暂无可用语音”，不许静默失败；
3. 按用户选择的发音精确匹配语音：美音选 lang 以 en-US 开头的语音，英音选 en-GB 开头；匹配不到时回退到任意 en 语音，并在设置处标明实际使用的语音，不许用错语言的语音硬读；
4. 只读单词本身：不读词性、释义、标点（如只读 hurricane，不读 hurricane n）；
5. 切题前先 speechSynthesis.cancel() 再 speak，防止上一题残音；语速 0.9–1.0、音量 1；
6. 状态可见：喇叭按钮要有播放中/失败两种可见状态；speak 失败时按钮旁给一句文字提示（如“朗读失败，点我重试”），喇叭按钮始终可手动点；
7. 禁令：发音链路是“本地音频 → IndexedDB → 在线接口 → 系统 TTS → 静默跳过”分层降级——禁止最后一级静默跳过。每一级失败都必须有可见反馈（日志或界面提示），最终兜底必须走到系统 TTS 或明确提示无可用语音；不许任何一级失败后悄无声息地没声。

### C-2 自动朗读 + 答错重读 + 拼写模式发音

- 每道新题出现时自动朗读该单词一遍（用用户选定的发音）；
- 答错时，在显示正确答案的同时把该单词再读一遍；反馈卡片上保留“再听一遍”按钮，可手动重听；答对不强制重读；喇叭按钮任何时候都可手动点；
- 拼写默写模式必须有英语发音：每题自动朗读英文单词一遍，题目旁放大号喇叭按钮可无限重听；默写就是听音写词，没有发音不成立；拼写判定不变（忽略大小写和首尾空格）。

### C-3 退出练习确认弹窗的两个按钮

- “结束并返回”文字是黑的：深色模式下黑字压在深色按钮上看不见。文字颜色必须跟随主题——深色下用浅色文字、浅色下用深色文字，不许写死黑色；建议用红色系区分这个 destructive 操作（深色下浅红文字 + 红边框，浅色下深红文字 + 红边框），与“取消”区分但两边都清晰可读；
- “取消”没对齐：弹窗底部按钮行改用 flex 布局、align-items: center，两个按钮同高（如 44px）、文字垂直水平居中、间距统一，不许一高一低、一大一小；
- 退出练习弹窗必修；其他确认弹窗（清空类、交卷类）顺带按同一规则检查一遍。

### C-4 例句朗读（检查项，不强行加页面）

- 检查词条详情/例句处有无朗读入口：有则保留并保证可点出声；若当前根本没有词条详情页，不要为此新建页面，在汇报里注明“无详情页、例句朗读未做”即可。

## D 部分：手机版专项（≤430px 宽度，桌面布局不要动，用媒体查询隔离）

1. 安全区：固定/吸顶顶栏加 padding-top: env(safe-area-inset-top)（constant() 兜底），底部标签栏加 padding-bottom: env(safe-area-inset-bottom)；不许写死像素值；灵动岛、刘海、Home 指示条都不能遮挡按钮；
2. 顶栏单行化：logo + 标题在左、按钮组在右，一行放完，不换行、不遮挡、不裁切（配合 A-1 的胶囊按钮）；
3. 全站禁止横向滚动：任何页面在 390px 宽下不得出现左右滑动，超宽元素自己内部处理，不许撑破页面；
4. 阅读：左右分栏改上下堆叠或“文章 / 题目”切换标签，不要把两栏硬挤在一起；计时器和交卷按钮始终可见可点；40 题题号格完整显示、每格可点；划词高亮工具条不超出屏幕边缘、不被吸顶顶栏盖住（位置做边界钳制）；
5. 写作：题目区、编辑区、统计面板上下堆叠；编辑区高度够打字，统计数字不挤成一团；工具条换行分组，但计时器、开始、交卷等关键按钮换行后仍完整可见；
6. 单词：卡片与按钮全宽排列，点击目标不小于 40px；导入文本框、筛选、列表、练习行在窄屏不溢出；
7. 范文：列表卡片单列，详情正文行宽适配手机，不用横向滚动；详情头按钮行换行；
8. 弹窗：一律居中、四周留边距，按钮可点，不许超屏；
9. 固定栏（顶栏 / 底部标签栏）不得遮挡正文内容：给页面加足上下滚动留白；
10. 手机端模块工具条取消吸顶或压成一行，只保留主顶栏吸顶（吸顶换行成 2–3 行会吃掉 200px 以上高度）。

### D-增补：实测量化清单（桌面端实测数字，换算到 390px 必然出问题，逐条达标才算过）

1. 顶栏单行内容总宽约 1260px，其中模块导航标签就超过 440px——手机上必须有移动端方案（导航进底部标签栏或横向滚动条），计时器、交卷、设置按钮不许被挤出屏幕；
2. 阅读题号格每格只有约 33×30px、角标小旗约 12px，远低于 40px 点击标准——手机端题号格放大到不小于 40×40（可减少每行列数或让题号区独立滚动），小旗热区同步放大；
3. 阅读左右两栏是固定高度、各自内部滚动——手机堆叠时不许保留双内滚：改成整页滚动，文章与题目自然衔接（或切换标签），不能出现两个小矮窗格；

6. 次要文字约 12px（题号数字、词数统计等）手机上偏小：手机端辅助文字不小于 12px 且保证对比度，正文维持约 15px 不动。
