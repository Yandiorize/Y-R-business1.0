1. 范文筛选列宽：列表页左侧筛选列放宽（现在约六分之一宽、字全站最小）。放宽后字号不再是全站最小；搜索、题型 tabs、细分题型、话题 chips、难度、计数、只看收藏/生词本/重置筛选全部可用；不得挤占右侧卡片区。桌面自测报数，移动端写“待真机验收”不得写成已通过。
2. 未录入题源置灰：来源选择器里未录入的套题禁用或标“暂未录入”（阅读 Test 2–4、写作剑 18/19 与 Test 2–4），不得像可选一样摆着。点到置灰项要有明确提示（不可选或提示暂未录入），不得跳到空白或错误页。
3. 图标颜色收敛：收敛到一主色 + 一链接色 + 一破坏色；模块图标靠形状和颜色区分，不得全是金色描边。金色主操作、紫色选中/趋势、蓝色链接三套竞争的现象消除；全站图标风格统一（笔触/圆角/粗细），三档尺寸。

## 硬规则

- 四项每项只有两种结果：改了（附改前/改后对照），或没改（附技术原因 + 替代改动 + 下一版计划）。不得出现“已优化”“已提升”等无证据词；每个这类词后面必须跟数字或截图，否则按未落地计。
- 不接受零改动交付：四项中不得以“现版已经很好”为由跳过任何一项；无法做的项必须给替代改动并等用户确认。
- 不动底线：localStorage 键 ielts.cbt.v1 + 数据结构不动；题目内容不动；评分算法不动；不加新模块；品牌必须 exactly “Y-IELTS”；内容区全实色。
- 更新日志只写真正落地的项，没落地的不得写进日志；版本号沿用 SW v43 的下一顺位，每项带 before/after。
- 交付格式：结论 + 四项逐项表（要求项 / 改前 / 改后 / 自测结果 PASS/FAIL + 证据）+ 一个下一步。没测的写“未测/待真机”，不得写成已通过。
