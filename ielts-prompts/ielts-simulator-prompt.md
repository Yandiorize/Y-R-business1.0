# IELTS 机考模拟器 — 综合修改提示词

> 使用方法：把下面整段内容复制，粘贴给 AI 编程助手（Cursor / Copilot / Claude 等），让它在你的项目代码上逐项实现。
> Logo 图标四个文件在 `~/workspace/` 目录下（`yandi-ventures-icon*.png`），先复制进项目再引用。

---

## 项目背景

- 纯前端静态网站（HTML / CSS / JS），无后端、无登录、无账号体系
- 所有用户数据保存在浏览器 localStorage
- 四个模块：
- **阅读 Reading**：剑桥雅思 17 Test 1–4，每套 3 篇文章 40 道题，60 分钟倒计时
- **写作 Writing**：Task 1（20 分钟）/ Task 2（40 分钟）切换，随机抽题，作答区实时字数统计，草稿自动保存
- **单词 Vocabulary**：词库导入/示例/导出/清空，四选一 + 翻卡自测，错词本、复习队列、学习统计
- **范文 Essays**：24 篇范文（Task 1 / Task 2 各 12 篇），搜索、筛选、排序、收藏、对照阅读
- 界面语言为中文，现有文案风格保持不变

## 第一部分：Bug 修复（必须全部修复）

### BUG-1全站"清空"类按钮失效

**现象**：以下按钮点击后均无任何反应，也没有确认弹窗——
写作模块"清空"、单词模块"清空词库"、阅读交卷面板"清空本套作答"。

**判断**：三个按钮同时失效，极大概率是共用的清空逻辑或事件绑定出了问题，请先检查公共代码。

**要求**：
1. 修复共用逻辑，让所有清空按钮恢复工作；
2. 所有清空操作必须先弹二次确认框（文案："确定要清空吗？此操作不可恢复。"），点确认后才执行；
3. 执行后清空对应数据并刷新 UI（作答区、字数统计、题号高亮、已答计数等同步更新）。

### BUG-2 阅读"重置"按钮行为不符合预期

**现象**：点击"重置"只把计时器归零到 60:00，答案、题号高亮、已答计数全部保留。

**要求**：点击"重置"弹出确认框，确认后同时重置计时器 **和** 清空本套所有答案（含填空文本、选项选择、题号高亮、已答计数）。

### BUG-3 Test 4 Q1–6 题型标签错误

**现象**：Q1–6 是 TRUE/FALSE/NOT GIVEN 判断题，题型标签却显示"填空"（Test 1 中同类题型标签为"判断"）。

**要求**：把 Test 4 Q1–6 的题型标签改为"判断"，与 Test 1 保持一致。

### BUG-4 文章标题缺失 / 截断

**现象**：
- Test 2 Passage 3：主标题只显示 "Reading Passage 3"，真实标题 "Insight or evolution?" 被降级为副标题；
- Test 3 Passage 2：主标题只显示 "Reading Passage 2"，无真实标题；
- Test 3 Passage 3：标题截断为 "Building the Skyline: The Birth and Growth of Manhattan's"（缺后半）；
- Test 4 Passage 2：主标题只显示 "Reading Passage 2"，"Does education fuel economic growth?" 为副标题。

**要求**：所有文章主标题显示真实完整标题，副标题样式的问题一并修正。

### BUG-5 字号切换顺序不合直觉

**现象**：循环顺序为 标准 → 较大 → 特大 → 较小（最小号紧跟最大号）。

**要求**：改为单调递增循环：较小 → 标准 → 较大 → 特大 → 回到较小。

### BUG-6 交卷后未锁定答案

**现象**：交卷后答题输入仍可修改；"已交卷"面板在切换题源再回来后消失。

**要求**：
1. 交卷后锁定本套所有答题输入（disabled），明确显示"已交卷"状态；
2. 提供"重新作答"按钮，点击经二次确认后解锁并清空本套答案；
3. 交卷状态按题源（Test 1–4）独立保存，切换回来后状态不丢失。

### BUG-7 单词模块首次进入残留旧数据

**现象**：新访客首次进入单词模块就已经有 50 个示例词和做题记录（开发调试时的 localStorage 残留）。

**要求**：
1. 区分"示例数据"和"用户数据"，首次访问默认不加载示例；
2. 词库为空时显示空状态 + 引导按钮"载入示例词表（50 词）"；
3. 在页眉"数据保存在本机"徽章旁（或新增设置区）加"清空所有本地数据"入口，需二次确认。

## 第二部分：功能增强（按优先级实现）

### P1-1 阅读交卷后显示答案对照与得分（价值最高）

在现有交卷面板基础上增加：
- 总得分：x / 40；
- 逐题对照表：题号 | 我的答案 | 正确答案 | 对错标记（答错标红）；
- 按题型分组的正确率统计（填空 / 判断 / 选择）。

### P1-2 写作基础评分

在现有字数统计旁增加（全部可纯前端实现）：
- 最低字数达标提示：Task 1 ≥ 150 词、Task 2 ≥ 250 词，未达标时红色提醒；
- 拼写检查：开启 textarea 原生 spellcheck；
- 衔接词 / 逻辑连接词出现次数统计（如 however、moreover、in contrast 等词表计数）。

### P2-1 阅读文章划词高亮

- 选中文章文本时弹出小工具条：高亮（黄 / 绿 / 粉三色）、清除高亮；
- 高亮数据随答案一起存入 localStorage，按题源独立保存。

### P2-2 题号格"标记待检查"

- 题号格支持三种状态：灰（未答）、绿（已答）、黄（标记待检查）；
- 点击题号可切换标记状态；交卷前提供"只看标记题"快速跳转。

### P2-3 考试倒计时提醒

- 剩余 10 分钟时计时器变红并轻微闪烁；
- 剩余 1 分钟时再加一次提示（toast 即可）。

## 第三部分：视觉优化

1. 计时器固定到顶部导航栏右侧，交卷按钮放在它旁边（贴近真实机考布局）；
2. 文章正文改用衬线字体（如 Noto Serif SC），行高 1.8–2.0，正文最大宽度限制在 65–75 个字符；
3. 文章段落加字母编号（A / B / C …），段落匹配题支持点击题干快速定位到对应段落；
4. 按钮视觉层级：主要动作（保存作答、交卷）用实心主色按钮，次要动作用描边按钮；
5. 单词模块学习统计：掌握率改用环形进度条，增加正确率趋势展示；
6. 所有空状态（词库为空、历史记录为空等）加引导文案和"去载入示例"按钮，不要只显示"0 条"；
7. 深色模式下检查范文模块中文批注高亮色的对比度，保证可读；
8. Task 1 图表图片确保清晰，支持点击放大查看。

## 第四部分：Logo 更换（炎帝 Yan-di 风格图标）

图标文件已提供（放在项目外的工作区目录，复制进网站静态资源目录如 `assets/` 或 `images/` 后再引用）：

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `yandi-ventures-icon.png` | 512×512 | 页眉 logo |
| `yandi-ventures-icon-180.png` | 180×180 | apple-touch-icon（iOS 添加到主屏幕） |
| `yandi-ventures-icon-192.png` | 192×192 | PWA 图标 / manifest |
| `yandi-ventures-icon-32.png` | 32×32 | favicon（浏览器标签页） |

**要求**：
1. 更新 HTML head：
   - `<link rel="icon" type="image/png" href="assets/yandi-ventures-icon-32.png">`
   - `<link rel="apple-touch-icon" href="assets/yandi-ventures-icon-180.png">`
2. 页眉 logo 的 `<img>` 换为 512 版本，显示高度建议 32–40px，旁边保留现有网站标题文字；
3. 该图标底色偏深：浅色页眉下检查对比度，如显暗，给 logo 外层加圆角深色底或柔光阴影保证辨识度；深色模式下可直接使用；
4. 如有 `manifest.json`（PWA），把 192 图标配置进 `icons` 字段；
5. 旧 logo 文件确认无其他引用后删除，避免残留。

## 全局约束（必须遵守）

1. 不引入后端、不引入登录，所有数据继续走 localStorage；
2. 不破坏现有正常功能：计时器、作答流程、单词测试流程、范文浏览、主题/字号切换；
3. 保持现有中文界面文案风格；
4. 移动端窄屏：左右分栏布局在窄屏下改为上下堆叠，确保手机可用；
5. 每个修改点完成后自测一遍相关按钮，确认无报错、无回归。
