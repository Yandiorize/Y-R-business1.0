# Super 超级改版方案（Y-IELTS 激进优化：UI + 功能，skills 最大功率）

> 定方案用：用户说“定”（或指出改哪里）之后，按此方案写 WB 提示词 super 版，用户分段发给 WB。
> 前置条件：WB 先按 wb-install-10-skills.md 把 skills 装好，否则提示词里的调用无从执行。
> 本方案取代 v18+skills 提示词（那份不再发）；v18+skills 是底子，super 在它之上加激进范围与最大功率调用。

## 一、现状结论（2026-10-24 扫 bug + 现状观察，同一构建）

- 构建：post-v18 同一构建（6 点对照 5 项一致；底栏遮挡在宽屏上本轮未复现，窄屏仍未验）。“我的”面板仍无更新日志一节。
- 壳已成型：胶囊顶栏 / 底栏、仪表盘、五卡、继续练习都在；视觉层级统一，不拥挤。
- 弱点（按用户体感排序）：
  1. 计数全线失真：单词每词 0/0 冻住、退出算轮次（0 答退出也算一轮）、阅读顶部 0/10 对 40、分类 16/11/4/9。
  2. 自相矛盾：单词退出弹窗写“本轮进度不保存”，退出后轮次却涨了。
  3. 设置保持分裂：主题 / 字号保持，玻璃滑杆 0% 刷新弹回 50%（文案还写着“刷新后保持”）。
  4. 入口重复与歧义：单词三开始、听力两交卷、继续练习跟“上次访问”不跟“上次交卷”（访问过写作就推写作，尽管唯一交卷是阅读）。
  5. 密度不均：首页卡片中间大段空白；听力左 panel 大面积空；单词 / 范文最密。
  6. 可信度缺口：范文 Test Test 1；更新日志缺失（v17.3 声称的修复多数不属实）；“我的”面板开着不刷新（词库 50 清零后仍显示 50，重开才变 0）。
- 结论：Super 不做“更漂亮的壳”，做“数字对、设置记得住、入口唯一、密度合理”——先让产品可信，再谈更美。

## 二、Super 的 finish line（定死，感觉换清单）

- 拦路项清零：单词循环（计数实时、轮次只计完成、0 答退出不计轮、扩轮必明示或不扩、翻卡背面有词有喇叭、再听一遍唯一、统计不滞后）、阅读（顶部 40、分类 11/11/9/9、格子按钮行为一致）、听力状态（播放前隐藏、题源重置回访都在、提交态与记录一致）、范文来源去重、滑杆保持、我的面板刷新。
- 入口唯一：单词一开始、听力一交卷、继续练习跟上次交卷 / 真实进度（规则写明，不跟访问记录）。
- 密度：首页卡片中间空白填上（进度 / 下一步，不加卡片尺寸）；听力左 panel 空区填上（当前句 / 进度 / 操作，不挤题目）；单词 / 范文密度保持可读（不为填而填）。
- 性能数：LCP ≤2.5s、INP ≤200ms、CLS <0.1（PageSpeed 改前改后两组数）；预算整页 <1.5MB、JS <300KB（压缩后）、CSS <100KB（压缩后）。
- 无障碍：WCAG 2.2 全量（44px、focus-visible、reduced-motion、对比度、键盘全通）。
- 打磨：impeccable detect 59 条全过（附 JSON 与退出码）。
- 视觉：ui-ux-pro-max 全套设计系统一次定齐（风格 / 色板 / 字体 / 布局 / UX 规范），图标三档统一；显著 + 超级标准保留（第一眼像换产品，至少三处不同，改前改后三组对比：首页、模块页、考试页）。
- 文案：humanizer 过一遍（关于、提示、空态、日志），具体数字、无套话。
- 汇报：i-have-adhd 格式（结论先行、编号、一个下一步）+ 四张表（skills 调用表、UI 验收、功能验收、优化对比表）。

## 三、范围与顺序（激进，但分阶段验收）

- 第 0 阶段（准备，WB 做）：装 skills 确认；graphify 建代码图谱 + ponytail-audit 先画地图（重构前摸清代码，不盲改）；上报图谱 / 地图 + 风险点。
- 第 1 阶段（功能线，优先）：单词循环重建、阅读计分重建、听力状态一致、设置保持修复、入口唯一、我的面板刷新。——先让数字和功能可信。
- 第 2 阶段（UI 线）：设计系统全套 + 图标重绘 + 密度（卡片中间、听力 panel）+ 三视口（390px 竖屏 / 手机横屏 / iPad 横屏，WB 自测数值）+ 玻璃壳参数上报。
- 第 3 阶段（优化线）：性能（INP / CLS / LCP）+ 无障碍全量 + best-practices + impeccable detect 全过 + 文案。
- 第 4 阶段（商业化产品侧）：更新日志补齐（只写实测落地的项；本版名 super；此前缺失的日志节补上）+ 记录跨版本完好复核。
- 验收方式：每阶段一张表；半落地就滚入下一版，不硬凑；版本门禁：每次发版先认版本（功能特征，不看 About 数字）。

## 七、网上学习补充（2026-10-24 研究，折进 super；证据等级见末尾）

### 采用：考试体验（对标 IDP 官方机考 chrome + computerielts 等）
- 阅读分栏独立滚动（已有雏形，保留并强化：左文右题，各自滚，不整页追遮）。
- 颜色导航：已答 / 未答 / 标记三色 + 已答 x/40 计数 + 交卷前回顾屏（答了什么、没答什么、标记了什么，可跳回）。
- 计时升级（修正此前写法）：10 分钟变黄、5 分钟红闪、到时自动交卷；写作 10 / 5 分钟提醒；听力留 2 分钟检查；另设不限时练习模式（与官方 familiarisation 对齐）。
- 听力：音量控制、单次播放纪律、原文只在交卷后回顾时给全（播放前隐藏已有，强化）。
- 写作：Task 1/2 切换 + 实时字数 + 自动保存（草稿自动加载已有，强化为每次输入都存）。
- 评分：听力 / 阅读交卷即出预估 Band + 逐题回顾（正确答案 + 证据定位）；Band 表写死（听力 30–31 = 7.0、学术阅读 30–32 = 7.0、总分 = 四项均值四舍五入到 0.5）；一律标“预估 / 仅供参考”。
- 首页层级：模块卡加时长 / 题数 / 难度（易 / 中 / 难）+ 按题型练入口（不加新题库，按现有题型筛选练）。

### 采用：学习循环（通用学习 UX）
- 错题本：答错自动归集，打三类标签（内容缺口 / 题干陷阱 / 粗心），48 小时内安排重测。
- 单词间隔重复：Again / Hard / Good / Easy 四档；答对 → 1 天 → 1 周 → 约 1 月；答错重置。
- 掌握度方格：每技能一格，颜色分级，点格即练（替代纯文字进度）。
- 继续练习：改为“下一步 + 进度条 + 上次断点续练 / 重练错项”，不再跟访问记录。
- 范文→单词闭环：范文短语点译 + 术语抽屉 + “加入单词本”；Simple / Advanced 双版本范文有条件时再做（不硬上）。
- 宽容连续性：每周 5/7 目标、冻结 / 宽限、软重置、按成果里程碑（不按打卡）；不写催促 / 内疚文案，不用爱心 / 生命值门槛。
- 防错流程：后退不丢数据、交卷前回顾屏、保存后继续（与 0.11 交卷前确认一致）。

### 不抄（静态替代方案）
