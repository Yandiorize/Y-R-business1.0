# 单词模块优化 — 练习模式改为全屏独立页

> 只做这一项，不要动词库页其他部分，不要改计分、错词本、统计逻辑。
> 现状：点“开始本轮”后练习嵌在词库页里的一张卡片中，顶部顶栏、底部标签栏、词库内容都还在，练起来分心。

## 要求

### 1. 进入方式：点“开始本轮”即进入全屏练习页

- 可以是独立路由/独立视图状态实现，不做硬性规定；但视觉上必须做到：**整个视口被练习页完全覆盖**——顶栏、底部标签栏、词库列表、其他卡片全部不可见、不可点。
- 全屏页高度用 100dvh，背景跟随当前主题（浅色浅底、深色深底）；上下左右留安全区边距（env(safe-area-inset-*)），灵动岛、Home 指示条都不能遮挡内容。

### 2. 全屏练习页结构（自上而下）

1. 顶部行：左侧“← 退出”，中间“第 x / y 题”+ 一条细进度条；
2. 题目区：单词/释义用大号字居中显示；有发音设置时，题目旁放一个显眼的朗读按钮；
3. 作答区：
   - 四选一：四个选项做成全宽大卡片，高度不小于 48px、间距充足，点后立即判对错；
   - 拼写默写：一个大号输入框（键盘弹起时内容区可滚动，输入框不被键盘盖住），点“提交”判对错，判定忽略大小写和首尾空格；
4. 反馈：答对卡片变绿、答错变红并显示正确答案，然后出现“下一题”按钮；不要自动跳题。
5. 本轮答错的词按现有规则在本轮末尾再出现一次（回炉），逻辑不变。

### 3. 结束与退出

- 最后一题答完 → 全屏结果页：本轮得分、正确率、错词清单，两个按钮：“重练错词”（只测本轮错词）、“返回词库”。
- 中途点“← 退出”→ 弹确认：“结束本轮并返回词库页？本轮进度不保存”；确认后回词库页，取消则留在练习页。
- 从结果页点“返回词库”后，词库页正常显示，错词本、统计已按本轮结果更新。

### 4. 不变的东西

- 方向（英译汉 / 汉译英 / 拼写默写）、形式、题量、范围、发音选项的生成逻辑全部照旧；
- 计分、错词本写入、学习统计的更新逻辑照旧；
- 词库页本身（导入/导出/清空/列表）一个字都不要改。

## 自测（逐项实际操作，全部通过才发布）

1. 点“开始本轮”→ 顶栏、底栏、词库内容全部消失，整屏只有练习页；
2. 四选一：答对变绿、答错变红 + 显示正确答案 + 下一题；
3. 拼写默写：输入正确拼写判对、输错显示正确答案；键盘弹起不遮输入框；
4. 中途退出弹确认，确认后回词库、取消后留在原题；
5. 打完一轮：结果页得分与错词清单正确；“重练错词”只测错词；“返回词库”后错词本与统计已更新；
6. 浅色、深色各一遍；手机、桌面各一遍。
7. 最后只汇报：改了哪几个文件 + 每项自测结果 + 发布链接。不要长篇解释过程。
