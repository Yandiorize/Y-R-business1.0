## 第一部分：确定要改的（已实测确认缺失或错误）

### FIX-1 Band 换算表最低档修正（小改）

现状：结果页 Band 换算把“5 及以下”一律算成 2.5，与标准 Academic 换算表不符。
改为：4–5 → 2.5，3 → 2.0，1–2 → 1.5，0 → 1.0。其余档位（6–7 → 3.0 及以上）不要动。
结果页显示与作答历史里的 Band 都要用修正后的换算。

### FIX-2 数据导出 / 导入全部数据（v2 遗留的唯一大缺口）

现状：全站只有单模块导出（写作 TXT、单词词库），没有整站备份。
要求：
1. 在页眉“数据保存在本机”徽章附近加“导出全部数据”和“导入数据”两个按钮；
2. 导出：生成 JSON 文件下载，文件名带日期，如 `ielts-backup-2026-10-20.json`；内容包含各题源作答与交卷记录、阅读高亮、写作草稿与历史、词库与学习统计、错词本、范文收藏；
3. 导入：选 JSON 文件后先校验格式（结构不对立刻报错、不写入），再弹二次确认，确认后才覆盖写入并刷新全部 UI；
4. 自测：导出一份 → 清空全部数据 → 导入刚才的文件 → 数据应完整恢复。

## 第二部分：先自查、缺了再补（每项先报状态：已有 / 半成品 / 没有）

### CHECK-1 考试倒计时提醒

目标：阅读剩余 10 分钟时计时器变红并轻微闪烁；剩余 1 分钟时 toast 提示一次。已有就跳过，没有就补上，不要重复触发。

### CHECK-2 PWA 真离线

现状：manifest 已有，但 service worker 此前只缓存音频，离线打不开。
要求：service worker 缓存全部静态资源（HTML/CSS/JS/图标）与题库数据，断网时能打开站点并正常做题；缓存版本更新时能自动换新版，不要让用户卡在旧缓存。

### CHECK-3 键盘与无障碍

逐项查：阅读填空 Tab 顺序合理、选择题方向键移动 + 回车确认；计时器与题号格有 ARIA 标签；错词本 / 范文有 @media print 打印样式；动画遵守 prefers-reduced-motion。缺哪项补哪项，已有别重写。

### CHECK-4 性能

1. 范文模块：列表只渲染卡片摘要，点进详情再加载全文；图片加 loading="lazy"；
2. localStorage 写入防抖：作答输入停顿约 0.5 秒后再写，不要每敲一个字全量写一遍。

### CHECK-5 分享与 SEO

补齐 <title>、meta description、Open Graph（og:title / og:description / og:image）；页眉或页脚加“复制分享链接”按钮，点击复制当前网址并给 toast 反馈。

### CHECK-6 移动端窄屏

窄屏（≤768px）下阅读左右分栏改上下堆叠，题号格、计时器、交卷按钮不被挤出屏幕；写作、单词、范文同样检查。已有适配就只报结果，不要大改布局。
