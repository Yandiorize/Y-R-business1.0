# IELTS 机考模拟器 — iOS 27 风格液态玻璃提示词（只调样式 + 一个透明度滑杆，不动其他功能）

> 使用方法：在 WorkBuddy 同一个任务对话里分段粘贴（每段开头加一句“还没发完，先存着别动手”，最后一段发完再说“发完了，开始执行”）。
> 项目现状：纯前端静态站（源码在 /workspace/ielts-app/），数据存 localStorage，液态玻璃 UI 已上线。
> 对标声明：以 iOS 27 的 Liquid Glass 为准——不是泛泛的毛玻璃。iOS 27 相对 iOS 26 没有推倒重来，而是精修：透明度可调、默认更高对比、边缘更锐利分层、折射感更强、层与层纵深分离更好。本份把这几点翻译成网页可实现的参数；玻璃参数以本份为准，取代玻璃综合版与极端强化版的参数。

---

## 一、iOS 27 标志功能：玻璃透明度滑杆（必做）

- 在主题设置区加一个“玻璃透明度”滑杆，连续可调：从“清晰”（接近实色）到“通透”（高度透明），默认停在中间档；
- 滑杆实时生效：拖动时全站玻璃透明度跟手变化（用 CSS 变量统一控制，如 --glass-opacity，铬层与容器层按比例联动）；
- 选择要记住：滑杆位置存 localStorage，刷新、切换主题后保持；
- 滑杆两端都要实测：拉到“清晰”端文字必须完全清晰可读，拉到“通透”端玻璃感必须明显（内容从下方透过来）。

## 二、默认渲染：高对比 + 更鲜艳（iOS 27 的默认取向）

- 默认档 = 中等透明度（铬层约 0.55、容器层约 0.75），不许默认就拉到最透；
- 默认渲染要比之前更鲜艳：玻璃层 saturate(1.4–1.8)，背景光斑色彩比之前浓一点，让玻璃看起来是“有颜色的光”，不是灰白雾；
- 文字对比优先：默认档下正文、题号、选项、按钮文字必须清晰可读——这是 iOS 27 精修要解决的核心问题，不许为了透牺牲默认档的可读性。

## 三、边缘：锐利分层 + 折射感（iOS 27 图标重绘的路子）

1. 边缘锐利：每层玻璃边缘清晰分明——1px 细边框 + 顶部 1–2px 高光边，不许边缘发虚、糊成一团；
2. 分层立体：图标、按钮、卡片做成多层结构——底色层 + 玻璃层 + 高光层，层与层之间有可见的分离（像 iOS 27 图标那种近 3D 的分层感），不许一层颜色糊到底；
3. 折射感：玻璃下的内容用 backdrop-filter: blur + 亮度/饱和微调模拟轻微折射；栏体、侧栏边缘的折射要延续到边缘（不许边缘处突然截断成实色）；
4. 图标保本色：图标颜色保持自身颜色，不许被下方背景透色带偏（iOS 27 侧栏图标就是修了这一点：图标保持本色、不洇到背景里）。

## 四、纵深分离：层与层一眼分开

- 背景、卡片、弹窗、悬浮栏之间用透明度差 + 模糊差拉开前后关系：背景最糊、卡片次之、弹窗与悬浮栏最实但仍透；
- 弹窗出现时，下方页面要有一层极淡的遮罩 + 模糊，让弹窗与页面一眼分开，不许弹窗和页面糊成一层；
- 栏体形态向 iOS 靠拢：顶栏、工具条、底部标签栏做成悬浮胶囊式——四周留边、大圆角、不贴边贴底，浮在内容之上（这是 iOS 液态玻璃的标志形态）；栏体已改矮、按钮已放大的要求同步保留。

## 五、深浅主题与动效

- 浅色：白底玻璃 + 深色字；深色：深底玻璃 + 近白字；滑杆位置在两套主题下都生效；
- 主题切换、滑杆拖动时玻璃参数平滑过渡约 200–300ms，不许生切；
- 按钮、选项悬停时透明度 +0.05–0.1、高光略亮，按下时透明度 −0.05；
- 遵守 prefers-reduced-motion：减动效模式下取消一切玻璃过渡与悬停光流动画。

## 六、可读性底线（iOS 27 精修的出发点，违反即为未完成）

1. 文字永远纯色，不许加透明度；长文区（阅读文章、范文正文、写作编辑区）容器透明度在默认档不低于 0.75；
2. 同一区域不许两层以上半透明叠加；
3. 玻璃栏下方滚动内容经过时，栏内图标文字仍可辨认；
4. 滑杆拉到“清晰”端时，全站必须回到接近实色、处处可读——这是给眼睛的兜底。

## 七、逐表面验收清单（改完按表自查）

- 滑杆：设置区有“玻璃透明度”滑杆，默认中间档，拖动实时生效、刷新后保持，两端各实测一遍；
- 顶栏、工具条、底部标签栏：悬浮胶囊式，边缘锐利带高光，内容从下方透过来，五个标签按钮清晰、选中态可辨；
- 阅读、单词、练习、反馈、范文卡片：分层立体、边缘清晰，正文锐利，背景光斑隐约透过；
- 图标：颜色保持本色，不被背景带偏；
- 弹窗：与页面纵深分离，按钮文字跟随主题、两按钮同高对齐；
- 浅色与深色各完整走一遍，默认档与滑杆两端都达标才算过。
