## 第 0 部分：头号特性——答对 / 答错提示音（必做）

### 场景：一切答题反馈点都要有提示音

- 单词三模式答题（英译汉 / 汉译英 / 拼写默写）：每答一题，判定完成的瞬间播放提示音；
- 阅读答题：选择题选定、填空题提交、交卷后每题对错揭晓时，同样播放提示音（交卷后批量揭晓时按题顺序短促连播，不许一次长鸣）；
- 听力答题：每空提交 / 整节交卷后对错揭晓时，同样播放提示音；
- 练习、测验、复习队列、错词本里的答题全部覆盖，不许有的场景有声、有的场景没声。

### 音色：答对与答错必须一听就区分

- 答对：清脆上扬——两声短音（如 C5 → E5 正弦/三角波），每声约 0.12–0.18 秒，总时长 ≤0.5 秒；
- 答错：低沉短音——一声低音（如 A3 单音或下行音），时长约 0.2–0.3 秒；
- 音量适中、不刺耳、不吓人；两音色差异必须大到不用看屏幕也能分辨。

### 实现：Web Audio 现场合成（不要 TTS 念、不要外部文件）

- 用 Web Audio API 现场合成提示音，不依赖外部音频文件、不接付费 API、离线可用；
- 不许用系统 TTS 念“正确 / 错误”代替提示音（TTS 慢、会和单词发音串音）；
- 提示音必须在用户手势链内可播（首题答题动作本身就是手势）；不得因音频上下文未解锁而静默。

### 开关：单独的“提示音”开关，默认开

- 设置里加一个单独的“提示音”开关，默认开；关掉则所有答题提示音静音；
- 该开关与“发音”开关分开：关提示音不影响单词发音，关发音不影响提示音；开关状态存 localStorage，刷新后保持。

### 单路纪律：提示音不许和别的声音叠

- 全站同一时间只允许一路音频：播提示音时停掉单词发音与听力音频；提示音播完不影响后续发音；
- 提示音与“答错重读单词”、“再听一遍”不许叠音：顺序是先提示音、再读词（或先读词、再提示音），不许同时响；
- 提示音时长短，不许拖长、不许循环、不许连播成串。

### 时机：判定瞬间响，不许延迟到下一题

- 答对提示音与“正确”反馈同时出现；答错提示音与正确答案显示同时出现；
- 不许等翻到下一题才补响上一题的提示音；不许答对答错共用一个音。

### 验收（六种组合全测）

| 模式 | 答对提示音 | 答错提示音 |
|---|---|---|
| 英译汉 | 清脆上扬 ✓ | 低沉短音 ✓ |
| 汉译英 | 清脆上扬 ✓ | 低沉短音 ✓ |
| 拼写默写 | 清脆上扬 ✓ | 低沉短音 ✓ |

另测：提示音开关关掉后，六种组合全部静音；提示音与单词发音、听力音频无叠音；阅读、听力答题反馈点各抽一题，提示音同样生效。
