## 0. 目标（极端 + 最便宜可用）

- 范围：学习区（view-learn）+ 留言板（view-comments）两页的 UI + 功能。首页、考试页、其他模块不在本提示词里（走 super 那条线）。
- 基线：先确认基线是 v48 新结构（学习区 + 留言板已存在、SW v48、liquid-glass-v50.css），直接重载看，不要用站内跳转看旧版；基线不对先报，不要在旧版上改。
- 极端：能改的全改到位，不留半吊子——全部状态、两档主题、三视口、零截断、零溢出、零死按钮；impeccable detect 全过才交付。
- 价钱：最便宜可用模型（见第 6 节）。

## 1. 调用的 skills（最好最适合，各管一摊）

- UI 系统：ui-ux-pro-max（出一套两页通用的设计系统：颜色、字阶、间距、圆角、阴影、动效曲线，两页不许各一套）。
- UI 质感：frontend-design（材质感、层级、玻璃质感、视觉打磨——质感归它）。
- 无障碍：accessibility（WCAG 2.2：对比度数值、44px 触靶、焦点可见、减动效、键盘路径）。
- 留言功能：form-design（留言表单全路径：必填、校验、未填完、提交中、提交成功、提交失败、空态；每个回答对应表单项标签；表单项 ID 稳定）。
- 功能测试：webapp-testing（两页全部流程实测：学习区 5 行跳转、留言提交/展示/清空、底导航 4 项、三视口）。
- 量化性能：performance + core-web-vitals（先测后改：LCP ≤2.5s、INP ≤200ms、CLS <0.1；两页 JS/CSS 预算内；改前改后各测一次，数字进表）。
- 质量与安全：web-quality-audit（全量审一遍）+ best-practices（留言用户输入渲染必须转义，不得 script 注入；localStorage 键不动）。
- 交前检测：impeccable（detect 全过才交付；未过的项列出并修到过）。
- 文案：humanizer（两页用户可见文案去 AI 味，说人话；不许出现实现结构说明）。
- 执行纪律：karpathy-guidelines（先想再写、简单优先、最小改动）+ ponytail（能复用不重写——复用已有的顶栏/底栏/卡片/弹窗实现，不另起一套）。
- 报告：i-have-adhd（结论 + 编号步骤 + 一个下一步）。
- 不调用：seo（工具页在分享链接后，不做公开页优化）、book-to-skill（没有书）、archify/diagram-design（两页不需要新架构图/流程图）、graphify/ponytail-audit（全站代码图是 super 第 0 阶段的事，本提示词不重复）、taste-skill（设计质量已由 ui-ux-pro-max + frontend-design 定，不另做 taste 裁决）。

## 2. 学习区 UI（方向：翻转行结构，不是调对齐）

- 每行左块两行——第 1 行模块名 + 时长/题数（按现有内容实标：阅读 40 题、听力 10 题、写作 Task 1/2、单词 50 词、范文 24 篇；难度分级只有把握才标，没有把握不标），第 2 行下一步完整句（整行宽度，永不截断）。
- 右侧只放紧凑状态 chip（Band/交卷数/词库数/收录数）+ chevron，两者垂直居中；左块/chip/chevron 同一基线，全行统一。
- 进度条要么做实（可见 + 带 x/y 或 % 标注），要么未开始模块直接去掉空轨道（改“未开始”chip），不许摆一条近乎空的细线当装饰。
- 各行靠时长/题数/状态区分，不许五张行除图标外长得一样。
- 副标题那句实现结构说明删掉（“五个模块都在这里。首页只显示进度和下一步。”不许出现）；“今天还没有练习记录”这行从学习区去掉（今日概览已在首页，不重复）。
- 底部栏优化【简单高效，不重做】（用户 21:09 底部设计 + 22:51 单词页截图实证）：只改 4 处，不动项数/顺序/标签/图标：① 内容区底部留白 = 底栏高度 + 安全区，末行永远不被底栏盖住（长页、短页都验，全站各页都验：首页/学习/留言/单词/考试页，不只学习区）；② 安全区用 env(safe-area-inset-bottom)，过 iPhone 小横条；③ 浮动胶囊化：四边留边距 + 圆角 + 阴影 + 玻璃（与顶栏一致），一眼就是悬浮层、不是页面内容；④ 选中态保持（一主色 + 实色图标/粗体标签，未选中弱化），不另起一套状态系统。触靶已够（4 项均分宽度），高度不动，不加中间大按钮、不去标签、不改动效。底栏是全站共享组件，本条一次改全站生效。用户 22:51 单词页截图：底部“支持分隔符…”段落末行被底栏盖住（新版 4 项底栏下仍在，不是旧缓存）——交付时附单词页底部截图证明末行完整可见。浅色/深色两档都验，附底部 before/after 对照（末行 + 安全区 + 胶囊三处）。

## 3. 留言板功能（本地留言，不造假）

- 留言表单：输入框 + 提交按钮；必填校验（空内容提交时明确提示，不得静默失败）；提交中状态；提交成功后留言出现在列表顶部 + 输入框清空；提交失败给可读原因 + 可重试。
- 留言列表：本地留言（存 localStorage、本机可见）按时间倒序；每条带时间；删除/清空有确认（复用现有确认弹窗样式，背景变暗不强模糊）。
- 诚实规则：不得放假冒用户评论充数——演示内容必须标示例；多人共享上墙需联网后端，本提示词不接后端、不编造评论（留到商业化阶段定）。
- 空态：无留言时给一句话 + 写留言入口，不得空白页。

## 4. 量化标准（数字说话）

- 性能：LCP ≤2.5s、INP ≤200ms、CLS <0.1；两页体积预算内；改前改后数字进表。
- 对比度：正文 ≥4.5:1、大字 ≥3:1，数值进表（不是“加深了”这种词）。
- 触靶：全部可点元素 ≥44px；按钮/导航逐项量。
- 零容忍：截断成“...”的语义不明文案 0 处；390px 横向溢出 0 处；死按钮 0 个；两页全部状态（空/有数据/提交中/成功/失败）全测到。
- 视口：390px 竖屏、手机横屏、iPad 各报表现 + 安全区 + 触靶；桌面通过不等于移动端通过，移动端项写“待真机验收”不得写成已通过。

## 5. 质化标准（质量说话）

- 层级：下一步最突出（字阶/颜色/位置），状态 chip 次之，装饰最末；一眼先看到动作，再看到状态。
- 区分：五张行一眼能区分（时长/题数/状态/图标形状颜色），不许只靠图标区分。
- 质感：玻璃只做壳（顶栏/底栏/卡片/弹窗），内容区全实色；半透明 + 顶部高光 + saturate，文字永远实色；深色档材质感同样成立，不得灰洗。
- 文案：humanizer 过一遍（按钮、空态、校验提示、成功/失败提示），去 AI 味；不许出现脚本路径/文件名/实现结构说明。
- 动效：统一曲线 cubic-bezier(.22,1,.36,1)，200–300ms，支持 prefers-reduced-motion。

## 6. 价钱（最便宜可用）

- 模型优先：Hy3（0.00x 限时免费，若还在）→ Deepseek-V4.1-Flash（0.11x，已验证过的小修成本约 5.4 credits）；不要默认 Hy4 preview（0.29x）/ Ultimate（1.20x）/ Kimi-K3（1.62x）。
- 批量：本提示词只做 2 页，批量小；送之前在模型选择器里复核当前费率（2026-10-20/21 的费率表可能已变）；用户 2026-10-24 报 600 credits 剩余，小任务在免费/便宜模型上成本可忽略。
