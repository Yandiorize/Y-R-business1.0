# Y-IELTS 源码补丁：玻璃化加强 — WB 提示词

（基于当前 SW v43 构建。执行前先完整刷新页面确认构建，CDN 刷新慢的话直接刷新 #reading 这类直链、不得只走站内跳转，不得在旧构建上改。）

## 改什么（玻璃加强，全是必做）

1. 玻璃语言统一全站壳：顶栏、底栏、模块卡、面板、弹窗全部同一套玻璃——折射到边缘、1px 边框 + 1–2px 顶部高光、saturate 1.4–1.8、chrome 透明度 ≈0.55 / 容器 ≈0.75、动效 200–300ms、hover +0.05–0.1 / press −0.05、支持 prefers-reduced-motion、文字永远实色。现在弹窗是纯白卡、与卡片玻璃语言不一致，必须改成一致。
2. 弹窗/抽屉背景：变暗 + 轻模糊，背景文字不得糊到完全看不清（保留上下文可读）。“我的”抽屉同理。现在是强模糊到看不清，必须改掉。（SW v43 验收：弹窗背景未落地，本补丁必做。）
3. 玻璃滑杆：加数字/档位标识（现在只有“玻璃 50%”+ 细轨道，点轨道会跳值）；滑杆调节实时生效；刷新后保持（已落地，保持，不得改崩）。0% 档保持更实更静。
4. 玻璃存在感加强：薄栏（顶栏、底栏）和卡片边缘的玻璃层次要肉眼可见（渐变透出、顶部高光、柔和阴影），不得做成不透明卡片冒充玻璃；也不得透到看不清字。
5. 深色模式下的玻璃也要验：深色 + 玻璃叠加不得糊字、低对比；浅色/深色/跟随系统三档都看一遍。

## 不动底线

- 内容区（阅读文章、写作编辑器、听力句子、范文正文）保持全实色高对比，玻璃不得透进内容区。
- 不堆超过 2 层半透明；不许两层以上嵌套圆角边框；左上汇总区只留一层。
- localStorage 键 ielts.cbt.v1 + 数据结构不动；题目内容不动；评分算法不动；不加新模块；品牌必须 exactly “Y-IELTS”。
- 移动端玻璃质感（真机壁纸、深色下的 blur/saturation）写“待真机验收”，不得写成已通过。

## 硬规则

- 每项只有两种结果：改了（附改前/改后对照），或没改（附技术原因 + 替代改动 + 下一版计划）。不得出现“已优化”“已提升”等无证据词；每个这类词后面必须跟数字或截图，否则按未落地计。
- 不接受零改动交付；无法做的项必须给替代改动并等用户确认。
- 更新日志只写真正落地的项；版本号沿用 SW v43 的下一顺位，每项带 before/after。
- 交付格式：结论 + 逐项表（要求项 / 改前 / 改后 / 自测结果 PASS/FAIL + 证据）+ 一个下一步。没测的写“未测/待真机”，不得写成已通过。
