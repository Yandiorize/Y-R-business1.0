## A 部分：紧急修复（用户 iPhone 实拍确认的 3 个 bug)

### A-1 浅色模式发黑发灰（最严重）

现象（已实测确认）：新版浅色模式下，四个模块的页面底色都仍然是深色渐变、只有内容卡片变浅；桌面端尚可读，但在 iPhone 上玻璃卡片半透明、深色底透出来，整页呈浑浊深灰（用户单词页实拍），说明小字、空状态文字（“词库还是空的”等）几乎看不见。也就是说现在的“浅色模式”只是卡片变浅、底色没变，不是真浅色。
排查：assets/js/theme.js 切换时 data-theme 是否正确设置且刷新不丢失；assets/css/styles.css、ios.css 里页面背景、玻璃表面、各类文字颜色是否走主题变量。
要求：
1. 浅色模式必须是真浅色：页面底色浅色不透明（或接近不透明），卡片白色玻璃，文字深色；
2. 不只改主文字——次级文字、提示小字、占位符、空状态文字、标签、禁用态文字在浅色下逐类检查对比度，全部清晰可读；
3. 深色模式保持现状，一个像素都不要动；
4. 自测：四个模块 + 任一弹窗，浅色/深色各看一遍。

### A-2 顶栏被灵动岛遮挡（iPhone 安全区）

现象（实拍）：灵动岛压住标题和顶栏按钮，右上角按钮还被屏幕圆角裁切。
要求：
1. 检查 viewport meta 含 viewport-fit=cover；
2. 固定/吸顶顶栏加 padding-top: env(safe-area-inset-top)（constant() 兜底旧系统），顶栏高度随之增加、内容下移；底部标签栏加 padding-bottom: env(safe-area-inset-bottom)；左右内边距同样考虑安全区；
3. 不许写死像素值，必须用 env() 让所有机型自动适配；
4. 顶栏下方若有无内容的空玻璃条容器（实拍里有一个），查明用途：是空占位就删掉或合进顶栏，不要留个空壳在页面上。

### A-3 顶栏设置图标对不齐、形状被压变形

现象（特写实拍）：清空（垃圾桶）按钮被挤成竖椭圆，旁边的字号“A”和主题（月亮）按钮是正圆，三个按钮大小形状不一致。
病根方向：按钮没定死尺寸，被标题用 flex 挤压收缩。
要求：顶栏所有按钮统一固定方形尺寸（如 40×40）、flex-shrink: 0、图标统一 20px 且水平垂直居中、按钮间距统一；空间不足时让标题文字省略号截断，永远不许挤压按钮；logo 与标题、按钮组三部分在同一基线对齐。浅色深色下各看一遍。

## B 部分：手机版专项改造（≤430px 宽度，桌面布局不要动，用媒体查询隔离）

1. 顶栏单行化：logo + 标题在左、按钮组在右，一行放完，不换行、不遮挡、不裁切（配合 A-2/A-3)。
2. 全站禁止横向滚动：任何页面在 390px 宽下不得出现左右滑动，超宽元素（表格、题号格、工具条）自己内部处理，不许撑破页面。
3. 阅读：左右分栏改上下堆叠（文章在上、题目在下）或“文章/题目”切换标签，二选一，不要把两栏硬挤在一起；计时器和交卷按钮在手机上始终可见可点；40 题题号格完整显示、每格可点；划词高亮工具条不超出屏幕边缘。
4. 写作：题目区、编辑区、统计面板上下堆叠；编辑区高度够打字，统计数字不挤成一团。
5. 单词：卡片与按钮全宽排列，点击目标不小于 40px；导入文本框、筛选、列表在窄屏不溢出。
6. 范文：列表卡片单列，详情正文行宽适配手机，不用横向滚动。
7. 弹窗：一律居中、四周留边距，按钮可点，不许超屏。
8. 固定栏（顶栏/底部标签栏）不得遮挡正文内容：给页面加足上下滚动留白。
9. 自测方法：把浏览器窗口拉到 390px 宽，四个模块逐个从头滑到尾，逐项对照上面 8 条汇报。

### B-增补：实测量化清单（审计实测数字，逐条达标才算过）

以下是桌面端实测的真实尺寸，换算到 390px 宽必然出问题，逐条处理：

1. 顶栏单行内容总宽约 1260px，其中模块导航标签就超过 440px——手机上必须有移动端方案（导航进底部标签栏或横向滚动条），计时器、交卷、设置按钮不许被挤出屏幕。
2. 阅读题号格每格只有约 33×30px、角标小旗约 12px，远低于 40px 点击标准，手机上必误触——手机端题号格放大到不小于 40×40（可减少每行列数或让题号区独立滚动），小旗热区同步放大。
3. 阅读左右两栏是固定高度、各自内部滚动——手机堆叠时不许保留双内滚：改成整页滚动，文章与题目自然衔接（或切换标签），不能出现两个小矮窗格。
4. 写作工具条单行约 1200px、单词练习行约 800px、范文详情头约 480px、词库工具行约 480px——手机上一律允许换行分组，但计时器、开始、交卷等关键按钮必须在换行后仍完整可见。
5. 顶栏和各模块工具条在桌面都是吸顶的——手机端若换行成 2–3 行，吸顶会吃掉 200px 以上高度：手机端模块工具条取消吸顶或压成一行，只保留主顶栏吸顶。
6. 确认弹窗桌面宽约 420px，比 390px 屏幕还宽——所有弹窗加 max-width: calc(100vw - 32px)，按钮高度保持 ≥44px。
7. 划词高亮工具条贴着选区弹出，选区靠近文章顶部时会被吸顶顶栏盖住——工具条位置做边界钳制：不得进入顶栏区域，宁可弹到选区下方。
8. 次要文字约 12px（题号数字、词数统计等）手机上偏小：手机端辅助文字不小于 12px 且保证对比度，正文维持约 15px 不动。

## C 部分：单词模块优化（在现有词库/测验/错词本基础上加，不要推倒重做）

### C-1 今日复习（间隔重复）

- 每个词新增记录：连续答对次数、上次复习日期、下次到期日；老词库数据自动补默认值，不丢词；
- 到期规则：连续答对 0 次 → 1 天后，1 次 → 2 天，2 次 → 4 天，3 次 → 7 天，4 次 → 15 天，5 次及以上 → 30 天；答错一次清零连续答对、次日再复习；
- 单词页顶部加一张“今日待复习 N 个”卡片，点进去进入复习队列：到期词优先、错词排最前；复习用现有测验形式即可，答完自动更新每个词的下次到期日；
- 验收：载入示例词表后做一轮测验，故意答错 2 个 → 第二天队列逻辑先不验，只验：答错的词出现在“错词/待复习”里、答对的词到期日被推后、卡片数字与队列数量一致。

### C-2 测验增强

- 新增“拼写模式”：看中文释义输入英文单词，判定忽略大小写和首尾空格，其余必须全对；答错立即显示正确拼写；
- 任何模式下，本轮答错的词在本轮结束前再出现一次（回炉题）；
- 测验结束页列出本轮错词清单，并有“重练错词”按钮，点了只测这些词。

### C-3 单词发音

- 词库列表、测验、复习里，每个单词旁加小喇叭按钮，点击用浏览器 speechSynthesis 朗读单词（英式发音优先，取不到就默认英语音色）；例句旁同样可朗读；
- 不许接第三方语音 API，不许产生任何费用。

### C-4 词库管理

- 顶部加搜索框（按英文或中文模糊搜）和掌握度筛选（全部 / 生词 / 熟悉 / 掌握 / 错词）;
- 每条词可编辑释义、可单独删除（删除不用二次确认，但要即时刷新列表；若已有编辑功能则只补缺的）;
- 导入去重：导入时已存在的单词跳过，导入完 toast 或小字报告“新增 X 个，跳过重复 Y 个”。

### C-5 学习小统计

- 单词页顶部（今日复习卡片旁）加一条小统计：今日新学 X · 今日复习 Y · 连续学习 Z 天 · 掌握度分布（生词/熟悉/掌握各几个，用一条三段色带表示，不要引图表库）;
- 数据来自现有本地记录，缺的历史按 0 处理，不报错。

## E 部分：自查补缺（逐项先报状态：已有 / 半成品 / 没有，缺哪补哪）
