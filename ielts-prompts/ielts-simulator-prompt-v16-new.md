## 第 0 部分：本版四件事（必做）

### 0.1 首页独立界面（头顶 Y-IELTS + logo，无顶部导航，无底部导航条，导航至五个学习模块）

- 首页为独立界面：启动后首先进入首页，不再直接进入阅读；
- 首页顶部只有品牌头：Y-IELTS + logo，不设顶部导航条（无模块 tab、无计时、无交卷等模块控件）；
- 首页界面不设底部导航条（用户称“底部刘海”即指此条）；
- 首页内容为通向五个学习模块的导航入口：阅读 / 听力 / 写作 / 单词 / 范文各一个入口（卡片或按钮），点击进入对应模块；
- 模块页保留底部导航条（含首页入口），以便从任意模块返回首页；
- 首页 logo 点击仍进“我的”（v16 行为不变）；
- 首页玻璃化：首页应用液态玻璃效果，与全站玻璃风格一致（毛玻璃卡片 / 半透明、圆角、柔和阴影）；玻璃上的文字必须清晰可读，不得因透明发虚；
- 验收：启动进入首页；首页顶部只有 Y-IELTS + logo；首页无顶部导航、无底部导航条；五个模块入口齐全可点；从模块可返回首页；首页玻璃效果可见且文字清晰。

### 0.2 写作作答区文字加深（占位文字与提示文字太虚）

- 写作作答区占位文字“在此输入你的作答...”加深；
- 占位文字下方三行提示加深：切换 Task 1 / Task 2 自动加载对应草稿；内容每 0.6 秒自动保存到本机浏览器；已开启浏览器拼写检查（红色波浪线只是提示，不影响保存）；
- 要求：浅色 / 深色下均清晰可读，不用过淡的灰色；不改变已输入正文的样式；
- 验收：占位文字与三行提示在浅色 / 深色下均清晰可读，对比度明显高于当前淡灰。

### 0.3 顶栏对齐（真机实测问题）

- 顶栏三按钮（清空 / 复习 / 主题）在顶栏内居中分布，不挤在左侧，与 Y-IELTS 左右平衡（左右留白大体对称）；
- 听力“重播”按钮：文字（连图标）在按钮内水平居中，不偏右；
- 验收：顶栏三按钮在栏内居中；重播文字在按钮内居中；并上报实测布局数值。

### 0.4 范文朗读（新功能）

- 范文模块提供朗读功能：每篇范文可点朗读播放（按钮放在范文卡片 / 范文详情内，明显可点）；
- 朗读用站内现有发音链路，口音跟随全局口音设置（美音 / 英音切换后朗读口音跟随）；
- 朗读可随时停止（播放 / 停止切换），朗读时有状态提示；
- 验收：任一篇范文点朗读能出声（真机以用户设备为准，浏览器端以无报错 + 状态变化为准）；可停止；口音切换后朗读口音跟随。
