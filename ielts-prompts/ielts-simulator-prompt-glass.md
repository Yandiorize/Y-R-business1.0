# IELTS 机考模拟器 — 液态玻璃综合提示词（只调样式，不动功能）

> 使用方法：在 WorkBuddy 同一个任务对话里分段粘贴（每段开头加一句“还没发完，先存着别动手”，最后一段发完再说“发完了，开始执行”）。
> 项目现状：纯前端静态站（源码在 /workspace/ielts-app/），数据存 localStorage，液态玻璃 UI 已上线。
> 本份说明：这是一份**只管玻璃样式**的综合版——把散在 v9 里 P-6（标签栏玻璃）、P-7（全站玻璃感）的要求合并成一套全站统一的玻璃参数。本份与 v9 一起发时，玻璃参数以本份为准（更细）；单独发时只改样式，不许动任何功能、数据、题库、发音逻辑。
> 背景：此前全站发雾发灰的教训是“半透明叠半透明 + 文字压在渐变上”；本份的玻璃感要建立在**可读性底线**之上，不是越透越好。

---

## 一、玻璃分两档（全站统一，不许各模块各做一套）

### 第一档：铬层（Bars）——最透

适用：顶栏、阅读工具条、模块工具条、底部标签栏、悬浮按钮、弹窗标题栏。

- 背景：半透明毛玻璃，backdrop-filter: blur(16–24px) + saturate(1.4–1.8)；
- 透明度：浅色下白底约 0.55–0.7，深色下深底约 0.5–0.65；页面内容从下方透过来，滚动时能看到内容在玻璃下流动；
- 边框：1px 细边框，浅色下白色约 0.5 透明度、深色下白色约 0.15 透明度；圆角与现有语言一致（栏体圆角、按钮胶囊）。

### 第二档：容器层（Cards）——次透，保证阅读

适用：内容卡片、文章卡片、题目卡片、练习卡片、反馈卡片、词库卡片、范文卡片、弹窗主体。

- 背景：半透明毛玻璃，backdrop-filter: blur(12–20px) + saturate(1.2–1.5)；
- 透明度：浅色下白底约 0.75–0.85，深色下深底约 0.7–0.8；比铬层更实，保证长文阅读不费眼；
- 边框与圆角：与第一档同一套（1px 细边框、同级圆角），只透明度不同，形成层级差。

### 不做玻璃的地方

- 正文、题号、选项文字、统计数字本身：永远纯色，不许给文字加透明度；
- 输入框内文字、已输入的写作草稿：纯色，不许透；
- 页面总背景：保留现有浅蓝紫渐变（浅色）/ 深色底（深色），玻璃是浮在它上面的层，不是再加一层渐变。

---

## 二、深浅主题适配（两套都必须好看）

- 浅色：白底玻璃 + 深色字 + 白色细边框；次级文字用深灰，不许用浅灰压在透底上；
- 深色：深底玻璃 + 近白字 + 白色低透明度细边框；次级文字用浅灰，不许用深灰压在透底上；
- 主题切换时玻璃参数跟随主题走，不许出现浅色玻璃配深色字看不清、或深色玻璃配深色字看不见；
- 选中态：铬层与容器层的选中项（当前标签、当前选项、当前题号）用主题色加深一档 + 边框提亮，与未选中项拉开差距，不许只靠透明度区分。

---

## 三、层级与光感（玻璃像玻璃的关键）

1. 层级差：铬层（第一档）比容器层（第二档）更透，弹窗比卡片更实一档（弹窗主体透明度再 +0.05–0.1），层与层之间用透明度差区分，不许全站一个透明度糊到底；
2. 边缘光：玻璃边缘保留一圈极细的高光边（顶部边框亮度略高于其他三边，模拟光从上方来），不要用粗阴影代替；
3. 阴影克制：阴影只做一层轻阴影（柔和、扩散小），不许玻璃 + 重阴影双重厚重；
4. 圆角统一：同一级容器用同一圆角值，不许一个卡片 8px、一个 24px；
5. 动效克制：主题切换、弹窗出现时的过渡不超过 200ms；遵守 prefers-reduced-motion（减动效模式下取消玻璃过渡动画）。

---

## 四、可读性底线（违反即为未完成，此前发雾的教训不再犯）

1. 文字对比度：正文、题号、选项、按钮文字、统计数字在两档玻璃上都必须清晰可读；文字不许直接压在页面背景渐变上——玻璃容器本身就是文字的衬底；
2. 不许两层以上半透明叠加：同一区域不许铬层玻璃上再叠容器层玻璃（例如吸顶工具条下方不许再压一张玻璃卡片贴着它），避免灰雾感；
3. 内容滚动到玻璃栏下方时：栏内图标与文字仍可辨认（必要时在栏体底部加一层极淡的渐变衬底，但不许改回实色）；
4. 长文阅读区（阅读文章、范文正文、写作编辑区）优先保证锐利：容器层透明度取第二档上限（浅色 0.85、深色 0.8），不许为追求透感把长文区做成第一档。

---

## 五、逐表面验收清单（改完按表自查）

- 顶栏：第一档玻璃，品牌 Y-IELTS 与胶囊按钮清晰；
- 阅读工具条 + 计时器：第一档玻璃，60:00 与进度条清晰，仍只有外层一层框；
- 底部标签栏：第一档玻璃，五个按钮（阅读 / 听力 / 写作 / 单词 / 范文）清晰、选中态可辨，栏体已改矮、按钮已放大，安全区留白保留；
- 阅读文章卡片 + 题目卡片：第二档玻璃，正文锐利；
- 单词卡片、练习卡片、反馈卡片：第二档玻璃，单词、词性 pill、选项、释义、例句、再听一遍按钮全部清晰；
- 默写页、英译汉题：第二档玻璃，输入框文字纯色，喇叭按钮清晰；
- 弹窗（退出确认、清空确认、交卷确认）：弹窗主体比卡片更实一档，按钮文字跟随主题（深色下浅色字、浅色下深色字），两按钮同高对齐；
- 浅色与深色各完整走一遍：同一页面切主题，玻璃与文字在两套主题下都达标才算过。

## 六、防假落地规则

1. 每一处汇报时写明：改了哪个文件 + 玻璃参数（blur 值、透明度、边框），只写“已改成玻璃”不算数；
2. 发布后必须用无痕窗口 / 新标签重新打开验证一遍，排除旧缓存假象；汇报里写明验证方式；
3. 发布时更新静态资源指纹或 service worker 缓存版本，确保用户刷新后拿到的是新版；
4. 只改样式：不许动功能逻辑、数据结构、题库、发音逻辑、本地存储；老数据必须完好；
5. 做不了的必须明说原因和替代方案，不许报“已完成”。
