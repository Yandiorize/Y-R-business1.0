## B1 单词学习循环（拦路项 1：计数、轮次、重复按钮、背面音频、重叠、统计滞后）

- B1-1 每词“累计答对 / 答错”冻住：现象：controversial 答对后仍“累计答对 0 次 · 答错 0 次”，advocate 答错后仍 0/0，但已答和轮次正确率动了。改法：每词答对 / 答错计数必须随每次作答立即 +1（与已答、轮次正确率同一数据源、同一时机更新）。验收：任一词答对后其累计答对变 1，答错后累计答错变 1；连续作答累计递增。
- B1-2 轮次虚增：现象：没答就退出不算轮次是对的，但一开始答题轮次就涨（0→1，换个模式又 1→2），一轮还没完成数就先上去了；趋势区文案还写“完成一轮后这里会出现正确率趋势”。改法：完成轮次只在真正完成一轮时 +1（答完本轮全部题目）；中途退出、切换模式不得 +1；趋势区只在完成轮次 ≥1 时出现。验收：开一轮答 1 题后完成轮次仍 0；答完一轮全部题目后变 1；中途退出、切换模式不涨。
- B1-3 答错无声扩轮：现象：答错 1 题后轮次从 20 题变 21 题（第 3/21 题，已答 2/21），屏上无任何解释。改法（二选一，推荐前者）：(a) 轮次长度固定不变，答错的词进错词本 / 复习队列（已有机制），不扩轮；(b) 如保留重排，必须在扩轮发生的当刻屏上明示（例如“答错的词已加入本轮复习，本轮 +1 题”）。验收：答错后轮次要么仍 20 题，要么屏上有扩轮说明；不得无声变 21 题。
- B1-4 两个“再听一遍”：现象：反馈卡片内一个、卡片下方又一个。改法：只留一个（保留反馈卡片内的，删下方的；或反之，统一只留一处）。验收：反馈态全屏只见一个再听一遍。
- B1-5 翻卡背面丢音频与英文词：现象：正面有词 + 喇叭，背面只有中文 + 不认识 / 模糊 / 认识，无喇叭、无英文词。改法：背面同时显示英文词 + 喇叭按钮（与正面同一发音入口），再加中文与三档评价。验收：翻到背面能看到英文词、能点喇叭重听，不用翻回正面。
- B1-6 特大字号词与词性 pill 重叠：现象：特大（4/4）下练习卡片里 controversial、advocate、diverse 的词性 pill 蹭到词尾字母（列表页无此问题，保持）。改法：练习卡片内词与 pill 的排布在特大字号下不得重叠（换行或间距兜底，以特大实测为准）。验收：特大下三词的 pill 与词尾字母无触碰、无遮挡。
- B1-7 总统计慢一步：现象：答完第 2 题还显示第 1 题的数据（100%、1 轮、1 答），移到下一题才变成 50%、2 答。改法：总统计随每次作答立即更新，不得等到下一题。验收：连续答 2 题后统计立即为 50%、2 答。

## B2 阅读计分（拦路项 2：题数、分类、死按钮）

- B2-1 顶部题数与总数对不上：现象：顶部“题 0/10”，页面却是“共 40 题 / 已答 0/40”。改法：顶部题数与页面总数统一为 40（已答 X/40），不得出现 0/10 与 40 并存。验收：顶部与页面同一总数 40，答 1 题后两处同步变 1/40。
- B2-2 分类 pill 分布错：现象：填空 0/16、判断 0/11、匹配 0/4、选择 0/9（总和 40 是对的，但分布错）；应为填空 11、匹配 9。根因：第 27–31 题的列表总结被算进填空。改法：Q27–31 题型归属改为匹配；修正后填空 11、判断 11、匹配 9、选择 9，总和 40。验收：四 pill 为 11/11/9/9；分题型正确率按修正后归属统计。
- B2-3 顶部题数按钮在题号格收起时点了没反应：现象：格子收起时点顶部题数按钮，格子不展开。改法：收起状态下点顶部题数按钮必须展开题号格（或跳到题号格）。验收：收起时点按钮 → 格子展开可见。

## B3 听力（拦路项 3：原文可见、回访丢控件）

- B3-1 播放前全文可见：现象：23 句原文在按播放前就全可见，播放失败后还可见。改法：播放前不显示完整原文；句子原文只在该句播放后（或交卷后回顾时）可见；播放前只显示题干 / 空格。验收：按播放前屏上读不到任何一句原文；播过的句子按规则可见；交卷后回顾可见。
- B3-2 题源 / 重置回访消失：现象：第一次进有题源 / 重置，回访只剩顶栏交卷，无题源选择、无重置。改法：题源选择与重置在每次访问都可见（修状态 / 显隐逻辑，不只首访）。验收：首次与回访均见题源与重置；重置可用（答 1 空后重置回 0/10）。

## B4 底部导航盖内容（拦路项 4）

- 现象：宽屏下固定底部导航盖住内容：单词“开始练习”按钮要滚动才露出来，范文最后一行卡片被截，阅读面板底边被遮。改法：内容区加底部留白（高度 ≥ 导航栏高 + 安全区），使所有可点内容与末行内容在不滚动到底时也不被导航栏遮住。验收：宽屏下单词开始练习按钮、范文末行卡片、阅读面板底边三处均完整可见、不被导航栏压住。

## B5 范文来源重复（拦路项 5）

- 现象：范文详情来源写“Cambridge IELTS 17 Academic · Test Test 1 · Task 2”。改法：来源去重，写“Cambridge IELTS 17 Academic · Test 1 · Task 2”（全站同类来源行一并检查，不得再有 Test Test）。验收：首篇范文来源无重复；抽查其余范文来源行无重复。

## B6 其他剩余 FAIL（小项，一并修）

- B6-1 首页三按钮组缺口：现象：首页顶栏只有“我的”一个按钮，从首页无主题 / 复习直达（写作、单词、范文页已居中；阅读、听力为考试条，按考试模式规则不算缺）。改法：首页补齐主题 / 复习直达（或等价入口），使三按钮组在首页也可达。验收：首页可见主题与复习入口且可点。
- B6-2 清空词库后今日新学不同步：现象：清词库后“今日新学”仍显示测试留下的 2。改法（二选一且文案一致）：(a) 清空词库同步清零今日新学；(b) 今日新学明确为当日累计、不随清库变，并在文案中说明。验收：清库后今日新学要么为 0，要么文案说明其为当日累计。
