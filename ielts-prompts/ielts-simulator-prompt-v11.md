# IELTS 机考模拟器 — 补丁提示词 v11（单词三种模式声音模块统一，叠加在 v10 之上）

> 使用方法：在 WorkBuddy 同一个任务对话里分段粘贴（每段开头加一句“还没发完，先存着别动手”，最后一段发完再说“发完了，开始执行”）。
> 项目现状：纯前端静态站（源码在 /workspace/ielts-app/），数据存 localStorage。
> 背景：三种练习模式的声音体验目前各管各——英译汉有喇叭 + 自动读、汉译英题面没有喇叭、拼写默写有大喇叭 + “新题自动朗读”复选框，界面与行为都不统一。本版只做一件事：把三种模式的声音收敛成同一套模块；不动其他功能。v10 的数值自证规则（第 0 部分）继续适用。

---

## 一、共用同一套声音模块（三种模式同源，不许各写一套）

1. 同一语音源：三种模式共用用户选择的发音（美音 en-US / 英音 en-GB 精确匹配，匹配不到回退任意 en 语音并标明实际语音）；切换发音后三种模式同步生效；
2. 同一解锁逻辑：语音解锁发生在用户手势里（点“开始本轮”时 getVoices + 极短测试音）；监听 voiceschanged，列表为空时延迟重试（如 3 次 × 300ms），仍为空要在页面上明确提示“当前设备暂无可用语音”，不许静默失败；
3. 同一状态显示：喇叭按钮播放中显示“播放中…”，失败显示“朗读失败，点我重试”，喇叭按钮始终可手动点；不许只用颜色变化表示状态；
4. 同一失败兜底：发音链路（本地音频 → IndexedDB → 在线接口 → 系统 TTS）任何一级失败都必须有可见反馈，最终兜底必须走到系统 TTS 或明确提示无可用语音；禁止最后一级静默跳过；
5. 同一切题逻辑：切题前先 speechSynthesis.cancel() 再 speak，防止上一题残音；语速 0.9–1.0、音量 1；只读单词本身，不读词性、释义、标点、选项。

## 二、三种模式统一的控件（同一位置、同一尺寸、同一文案）

每种模式题面统一标配以下控件，位置、尺寸、样式三模式一致：

1. 常驻喇叭按钮：题目旁常驻一个喇叭按钮，点按朗读（读什么见第三条各模式规则）；
2. “发音”开关：统一文案就叫“发音”，开关样式统一（拼写默写现有的“新题自动朗读”复选框改名/改样式统一成这个开关）；开 = 新题自动朗读，关 = 只手动点喇叭才读，默认开；开关状态三种模式共用（在一个模式里关掉，其他模式同步关掉）；
3. 答错重读：答错时在显示正确答案的同时把该单词再读一遍；
4. 反馈卡片“再听一遍”按钮：答后反馈卡片上统一有“再听一遍”按钮，可手动重听；答对不强制重读。

## 三、各模式朗读内容规则（统一模块，但汉译英有防剧透例外）

- 英译汉（看英文单词选中文释义）：题目就是英文单词本身——新题自动朗读该单词，喇叭点按重读该单词；
- 拼写默写（听音写词）：新题自动朗读英文单词一遍，喇叭可无限重听；默写就是听音写词，没有发音不成立；
- 汉译英（看中文释义选英文单词）：**防剧透例外**——答前不许朗读目标英文词（否则等于直接泄题）。答前题面喇叭按钮置灰并注明“答后可听”；答后反馈卡片读正确英文词一遍 + “再听一遍”按钮可重听。开关与状态文字与其他两种模式一致，只是答前不发声。

## 四、界面统一（声音控件的界面优化）

1. 喇叭按钮在三种模式题面的位置一致（题目旁同一侧）、尺寸一致、样式一致，不许一个模式大、一个模式小、一个模式有、一个模式无；
2. “发音”开关在三种模式设置区的位置与样式一致；
3. 状态文字（播放中… / 朗读失败，点我重试）在三种模式的显示位置与样式一致；
4. 本版只统一声音模块及其控件，不动三种模式的题目逻辑、选项逻辑、计分逻辑。

## 五、验收（三种模式各做一题，对照表逐项打勾）

| 检查项 | 英译汉 | 汉译英 | 拼写默写 |
|---|---|---|---|
| 题面常驻喇叭按钮 | 有，点按出声 | 答前置灰“答后可听”，答后可用 | 有（大号），点按出声 |
| 新题自动读（开关开时） | 读题面词 | 答前不读（防剧透） | 读题面词 |

| 播放中 / 失败文字 | 有 | 有 | 有 |
| 答错重读 + 反馈“再听一遍” | 有 | 有（读正确词） | 有 |
