# 顶栏设置按钮手机端变形修复（单独小批量）

> 只修这一项，不要动其他任何功能和样式。
> 背景：v4 的 A-3 在桌面宽度下已是等大正圆，但用户 2026-10-21 手机实拍证明，手机宽度下问题仍在。

## 现象（用户手机实拍，浅色模式）

顶栏右侧三个按钮——清空（垃圾桶）、字号 A、主题——在手机宽度下都被压成椭圆，且三个宽度各不相同（垃圾桶最窄，A 与主题更宽）；桌面宽度下是正常的正圆。说明问题只在手机宽度下出现。

## 病根方向

按钮没有固定正方形尺寸，窄屏下被标题和顶栏容器挤压收缩；三个图标本身宽度不同，按钮宽度跟着图标走，所以三个椭圆宽窄不一。

## 要求

1. 三个按钮统一固定尺寸（如 40×40），加 aspect-ratio: 1 和 flex-shrink: 0，图标在按钮内水平垂直居中、统一 20px；
2. 按钮之间间距统一；空间不足时标题文字用省略号截断，永远不许挤压按钮；
3. 顶栏容器本身的高度不许把按钮拉成椭圆：按钮尺寸只由自身宽高决定，不随容器拉伸；
4. 浅色、深色下各看一遍；手机宽度（390px）下三个按钮必须是大小一致的正圆，桌面宽度保持不变。

## 自测

手机宽度下检查：三个按钮等大正圆、对齐成行；桌面宽度下不变。最后只汇报改了哪个文件 + 自测结果 + 发布链接。
