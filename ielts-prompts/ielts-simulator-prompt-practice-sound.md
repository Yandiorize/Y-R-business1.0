# 单词练习页一批修复：声音、自动朗读、填满下方、词性字号、退出弹窗按钮

> 只改单词练习页，不要动词库页、计分、错词本、统计逻辑。
> 背景：练习页声音完全没声（按手动点喇叭也没声来排查）；题目区“单词 + 词性”现在是同一个字号；页面下半部分大片空白；退出练习确认弹窗里“结束并返回”文字是黑的（深色下看不见）、“取消”与它没对齐。

## 1. 修声音：完全没声（先修好这一项，后面的自动读才有意义）

按以下顺序排查并修复（speechSynthesis 方案，不接任何付费语音 API）：

1. 语音解锁必须发生在用户手势里：点“开始本轮”时，先调用 speechSynthesis.getVoices() 并播一句极短测试音（或 cancel + resume）完成解锁；之后每题的朗读复用已解锁的语音通道，不许在非手势回调里从零初始化；
2. 语音列表是异步加载的：监听 voiceschanged 事件，等列表就绪后再 speak；首次列表为空时延迟重试（如 3 次 × 300ms），仍为空要在页面上明确提示“当前设备暂无可用语音”，不许静默失败；
3. 按用户选择的发音精确匹配语音：美音选 lang 以 en-US 开头的语音，英音选 en-GB 开头；匹配不到时回退到任意 en 语音，并在设置处标明实际使用的语音，不许用错语言的语音硬读；
4. 只读单词本身：不读词性、释义、标点（如只读 hurricane，不读 hurricane n）；
5. 切题前先 speechSynthesis.cancel() 再 speak，防止上一题残音；语速 0.9–1.0、音量 1；
6. 状态可见：喇叭按钮要有播放中/失败两种可见状态；speak 失败时按钮旁给一句文字提示（如“朗读失败，点我重试”），喇叭按钮始终可手动点。

## 2. 自动朗读 + 答错重读（建在修好的声音上）

- 每道新题出现时自动朗读该单词一遍（用用户选定的发音）；
- 答错时，在显示正确答案的同时把该单词再读一遍；反馈卡片上保留“再听一遍”按钮，可手动重听；
- 答对不强制重读；喇叭按钮任何时候都可手动点。

## 3. 填满页面下方空白

- 练习页内容整体垂直居中，不许题目挤在顶部、下面空一半；
- 单词字号放大，选项卡片加高、间距加大；
- 答题后在题目下方出现反馈卡片：中文释义 + 例句 + “再听一遍”按钮（例句只在答后出现，答前不剧透）；
- 底部保留一排小统计：本轮已答 x / y、正确率。

## 4. 词性字号必须小于单词字号

- 题目区“单词 + 词性”拉开层级：单词大字号加粗，词性用约 55%–65% 的字号、颜色弱化、与单词基线对齐（不要做成两个一样大的词并排）；
- 词库列表行如果也是单词与词性同字号并排，同步按同样规则改。

## 5. 退出练习确认弹窗的两个按钮

- “结束并返回”文字是黑的：深色模式下黑字压在深色按钮上看不见。文字颜色必须跟随主题——深色下用浅色文字、浅色下用深色文字，不许写死黑色；建议用红色系区分这个 destructive 操作（深色下浅红文字 + 红边框，浅色下深红文字 + 红边框），与“取消”区分但两边都清晰可读；
- “取消”没对齐：弹窗底部按钮行改用 flex 布局、align-items: center，两个按钮同高（如 44px）、文字垂直水平居中、间距统一，不许一高一低、一大一小；
- 退出练习弹窗必修；其他确认弹窗（清空类、交卷类）顺带按同一规则检查一遍。

## 自测与汇报

- 手动点喇叭出声；点“开始本轮”第一题自动出声；切题出声且不串音；答错自动重读一遍；答对不重读；
- 题目区单词大、词性小；页面上下分布均匀、无大片空白；答后反馈卡片（释义 + 例句 + 再听一遍）正常出现；
- 退出练习弹窗：深色、浅色下“结束并返回”文字都清晰可读，两个按钮同高、对齐成行；点取消回练习页、点结束并返回回词库页；
- 手机、桌面各一遍；浅色、深色各一遍。
- 注意：声音最终以用户真机验收为准（开发环境能出声不代表用户设备能出声），汇报时写明语音匹配逻辑与失败提示，不要只写“已修复”。
- 最后只汇报改了哪个文件 + 每项自测结果 + 发布链接。
