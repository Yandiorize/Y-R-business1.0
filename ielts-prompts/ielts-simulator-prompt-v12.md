# IELTS 机考模拟器 — 补丁提示词 v12（听力播放 robustness：断续 / 串音 / 卡顿 / 有时没声，叠加在 v10、v11 之上）

> 使用方法：在 WorkBuddy 同一个任务对话里分段粘贴（每段开头加一句“还没发完，先存着别动手”，最后一段发完再说“发完了，开始执行”）。
> 项目现状：纯前端静态站（源码在 /workspace/ielts-app/），数据存 localStorage。
> 背景：用户实测听力四症状——断断续续、串音、会卡、有时没声。本版只修听力播放逻辑，不动题目内容、题库、其他模块。v10 的数值自证规则（第 0 部分）继续适用（布局类附数值；代码类附文件名 + 行号）。

---

## 一、根因（先按这个查，不要只调参数碰运气）

1. 断断续续 / 会卡：听力文本整段几百词一次 speak——长 utterance 在浏览器 TTS 里容易中途停顿、卡住（iOS Safari 长句停顿问题尤其明显）；
2. 串音：切题、重播、手动点喇叭之前没有 cancel()，多路 utterance 排队叠加；或听力音频与单词发音同时在播；
3. 有时没声：语音列表未就绪就 speak，或上次播放异常后合成器卡死、后续 speak 静默失败，又没有任何提示。

## 二、改法

### 1. 分句切分播（治断续、治卡）

- 听力文本按句子切分（句号 / 问号 / 感叹号 / 分号 / 换行）成短句队列，逐句顺序播；句间停顿 300–500ms；
- 不许整段几百词一次 speak；不许用一个超长 utterance 播完整段；
- 每句播完再播下一句（onend 驱动），不要一次性把几十句全塞进队列。

### 2. 单路纪律（治串音）

- 全站同一时间只允许一路音频：播听力时停掉单词发音，点单词喇叭时停掉听力；
- 每次 speak 之前必 speechSynthesis.cancel()；重播、切题、暂停后继续、手动点喇叭，全部先 cancel 再 speak；
- 禁止 utterance 排队叠加：队列里永远只有当前句 + 最多一句待播，不许攒一串。

### 3. 防卡死复位（治有时没声）

- speak 前检查合成器状态；若上次播放异常结束/卡住，先 cancel() 复位再播；
- 单句超时保护：单句超过合理时长无进展（如 15 秒无 onend 且无状态变化），cancel + 重播该句一次，仍失败则显示失败提示，不许悄无声息停住；
- 首次播放必须在用户手势里解锁（点播放时 getVoices + 极短测试音）；等 voiceschanged 就绪后再播；列表为空时延迟重试（如 3 次 × 300ms），仍为空明确提示“当前设备暂无可用语音”，不许静默没声。

### 4. 状态可见与断点续播

- 播放中显示当前句高亮（播到哪句亮哪句）+ 进度（第 x / y 句）；
- 暂停 / 继续 / 重播按钮状态同步：暂停后继续从当前句续播，不从头；重播从本段开头播；
- 中断恢复：页面切后台、锁屏等导致中断后，回来可从当前句续播；
- 失败显示“播放失败，点我重试”，喇叭/播放按钮始终可手动点。

### 5. 与单词声音模块的关系（v11 已统一的那套）

- 听力播放复用 v11 的同一套声音模块：同一语音选择（美音 en-US / 英音 en-GB）、同一解锁逻辑、同一状态文字、同一失败兜底；不许听力单独写一套；
- “发音”开关状态与单词模式共用：关掉发音时听力也不自动读（只手动点播放才读）。

## 二补充、实测追加（2026-10-21 专项检查坐实，最高优先级）

- 实测：听力模块能打开（只有剑 17 Test 1 Section 1 一个选项，10 题 · 对话 · 约 2 分钟），题目全部能正常填写（Q1 填入后计数 0/10 → 1/10），但点播放后 90 多秒完全没声、卡在 23 句中的第 1 句、进度条不动、按钮一直停在“播放”没变成播放中/暂停状态、没有任何警告；再点一次播放也没有任何变化。也就是说：断续、串音、卡顿在你设备上的种种表现，在这边是更严重的一档——第一句就彻底停住。
- 由此追加三条必做：
  1. 第一句卡住必须有失败提示 + 按钮状态必须变化：点播放后若首句在合理时间内（如 5 秒）没有出声、没有进度，立即显示失败提示（不是悄无声息停住），按钮必须从“播放”变成播放中/暂停态，状态变化本身就是验收项；
  2. 必须有暂停与重播按钮：现在只有“播放”和“重置”两个按钮，没有暂停、没有重播——补上暂停 / 继续 / 重播（重播从本段开头播），重置后回到“点击播放开始”；
  3. 本地音频优先链路要验真：页面脚注写明“优先播放本地音频文件；未配置时使用系统语音逐句朗读”——实测走的是系统语音兜底且卡住。改法：若配置了本地音频文件，必须验证文件真实可播（不是只写了路径）；若未配置，TTS 兜底失败时必须有可见警告，不许无声无息。

## 三、验收（用一个完整 Section 实测）

1. 连续播完一整个 Section：不断续、不串音、不卡、无中途停住；
2. 中途暂停 1 次、重播 1 次、切题 1 次：每次之后都只有一路声音，无叠加、无残音；
3. 播听力时点单词喇叭、点单词喇叭时播听力：后点的停掉先点的，全站永远只有一路声；
4. 断网/无语音条件下：有明确提示，不许静默没声；恢复后可重试出声；
5. 暂停后继续：从当前句续播，不从头。
