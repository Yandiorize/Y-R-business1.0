## 第 0 部分：头号——删除答错自动重读（必做）

### 删什么

- 单词三模式（英译汉 / 汉译英 / 拼写默写）答错后自动朗读正确词的功能，全部删除；
- 阅读、听力答错后如有类似的自动朗读，也一并删除；
- 删干净：答错反馈路径上不得残留 speak 调用，不得残留“答错后读词”的定时器 / 回调 / 队列。

### 保留什么（不许误删）

- v13 的答对 / 答错提示音保留：判定瞬间该响的提示音照常响（答对清脆上扬、答错低沉短音）；
- 反馈卡片里的手动“再听一遍”按钮保留：用户想听再点，不自动播；
- 新题自动朗读（“发音”开关）保留：下一题该自动读的照常自动读；
- 错词本记录逻辑不动：答错的词照常进错词本 / 复习队列。

### 为什么删（写给执行者的上下文，不要外泄给用户界面）

该功能跨模式表现一直不一致（某版只有默写有、某版英译汉汉译英有了默写反而丢了），且与提示音、单词发音争同一路音频，是叠音 / 静默 bug 的来源之一。删除后答错反馈链路只剩“提示音 + 手动再听”，最短、最稳。

### 删除后答错流程

答错 → 答错提示音（低音）→ 反馈卡片（释义 + 例句 + “再听一遍”按钮）→ 错词本记录。8 秒内不得有任何自动朗读。

### 验收

三模式各故意答错一题：答错后 8 秒内无任何自动朗读（只听见答错提示音）；点“再听一遍”仍能手动播正确词；“发音”开关开时下一题仍自动读；阅读、听力答错后同样无自动朗读。

## 第 1 部分：本版优化——Band 趋势 + 按题型正确率

### 自动记录每次交卷成绩

- 每次阅读交卷后，自动记一条历史记录：日期 + 分数（x/40）+ Band 分 + 各题型正确率，存 localStorage；
- 不改计分、不改题目内容、不改 Band 换算规则；只用本地数据，不上传；
- 记录随现有的“清空所有本地数据”清除（与现有清除逻辑一致），不另搞一套清除规则。

### Band 趋势图

- 按时间顺序画 Band 变化（折线或柱状均可），显示最近的记录（至少最近 10 次），一眼看出进步 / 退步；
- 每个点标注日期 + Band 分；空状态：没有任何交卷记录时显示“暂无记录，交卷后自动记录”，不许画一条假的空图；
- 入口必须找得到：交卷结果页能看到趋势，阅读模块内也要有一个固定入口（统计 / 记录入口均可）。

### 按题型正确率

- 交卷结果页增加按题型正确率（判断 / 选择 / 填空 / 配对等有几类算几类，每类“对 x / 共 y 题”）；
- 再加一组历史平均条形：最新一次 vs 历史平均并排显示，一眼看出哪类题最弱；
- 每类错题列出题号，点击可跳回原文定位（已有定位逻辑则复用）。

### 验收

交卷 2 次 → 趋势图出现 2 个点，Band 值与两次成绩一致；按题型条形与本次 / 平均一致；清数据后空状态显示“暂无记录”；旧词库、旧数据完好。
