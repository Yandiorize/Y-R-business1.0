## 第 0 部分：本版十一件事（必做）

### 大改版总原则：上部极简、内容优先（用户 2026-10-23 反馈：学习模块被上部分挡得太多、界面太乱；本原则高于各单项，单项与总原则冲突时以总原则为准）

- 学习模块页上部只保留最必要的元素（返回 / 标题 / 计时），其余全部收进抽屉、底部或可收起区域；顶部不得以多层卡片 / 药丸 / 工具条叠加遮挡学习内容；
- 内容区全屏优先：文章、题目、编辑器、听力句、范文正文占满主视野，上部 chrome 不得挤占、不得悬浮盖住学习内容；
- 界面不乱：同一页面只留一套导航（顶栏或底栏，不双份）；同一区域只留一层卡片（不嵌套）；状态信息（题数、计时、交卷）合并为一行，不铺多行；
- 本原则统一解决此前全部“上部挡视野”问题（环套叠、题号格占半屏、顶栏拥挤、三按钮组位置），不再单点修补。

### 对标：学为贵（刘洪波）web（2026-10-23 实地学习，v.guixue.com/ielts/，未登录可看）

- 学：顶栏薄（约 9% 视野）且不压内容；模考考试条 + 居中单卡片、无广告无侧栏无悬浮物；阅读左题右文各自独立滚动（滚动在分栏内，不整页追遮）；一屏一主任务（选题→说明→答题→确认分步走）；计时 / End Test / 字数同在一考试条；提交前二次确认、空写作拦截、提交后就地展开答案不跳转；
- 不学：正题无题号导航盘 / Review 屏（说明承诺了但实际没有）；模考 End Test 无分数页、直接回选题页；写作 End Test 跳错误页；标题拼写错误、计时 00:00:00、进度全 60% 等粗糙处；

### 0.3 液态玻璃（iOS 27 + Windows 毛玻璃，只做壳）+ 设计系统定标

- 风格定调（我定的）：iOS 27 Liquid Glass 为主 + Windows 毛玻璃（Acrylic / Mica）做底子，两者融成一种玻璃，不另起一套。参数直接沿用之前那份 iOS 27 玻璃提示词，不改口径；
- Windows 毛玻璃底子：backdrop blur + 微透 + 主题色 tint + 极淡噪点质感；层级按 Mica / Acrylic 分层：背景最糊、卡片次之、弹窗与悬浮栏最实但仍透；弹窗出现时下方页面加极淡遮罩 + 模糊，纵深一眼分开；
- iOS 27 液态玻璃面上：栏体做成悬浮胶囊式（四周留边、大圆角、不贴边贴底）；每层玻璃 1px 细边框 + 顶部 1–2px 高光边，边缘锐利不发虚；多层结构（底色层 + 玻璃层 + 高光层），折射延续到边缘、不突然截断成实色；玻璃层 saturate 1.4–1.8、背景光斑稍浓；图标保持本色，不被背景透色带偏；默认档铬层约 0.55、容器层约 0.75，不许默认就拉到最透；主题切换、滑杆拖动过渡约 200–300ms；悬停透明度 +0.05–0.1、按下 −0.05；遵守 prefers-reduced-motion；
- 范围（我定的）：玻璃只做“壳”——顶栏、底部栏、模块卡片、面板、弹窗；答题内容区保持素面高对比，不得用玻璃材质：阅读文章、写作编辑区、听力句子、范文正文一律素面。这比之前 iOS 27 提示词的“长文区不低于 0.75”更严，因为 20:54 用户 iPad 照片里写作提示仍偏淡，0.75 在真机上不够；机考模拟以真实机考为准，长文必须耐读；
- 硬约束：壳上玻璃文字必须可读——玻璃面板下加遮罩 / 渐变衬底，正文对比度在浅色 / 深色下均达标；文字永远纯色，不许加透明度；同一区域不许两层以上半透明叠加；写作提示、占位文字不得再偏淡（与 v17 0.3 合并验收）；
- 设计标尺一次定：字重（正文不得用 thin / light，标题 / 导航 / 按钮用粗体，上报改前 / 改后数值）、字号、间距、按钮尺寸（触控目标不小于 44px）、圆角；
- 圆角框不嵌套：同一区域圆角框不许嵌套两层以上；所有模式左上角汇总区（卡片环 + 中间环 + 题数药丸环，三层套叠）全部减为单层——一张卡片，题数、计时、交卷直接排在里面，不再套环（用户 2026-10-23：左上角环太多，所有模式左上角要改）；
- 玻璃透明度滑杆保留可用（默认值 50 不变，中间档），拖动实时生效（CSS 变量统一控制）、存 localStorage、刷新与切换主题后保持；滑杆两端都要实测：拉到“清晰”端全站接近实色、处处可读，拉到“通透”端玻璃感明显；
- 验收：上报字重数值 + 壳上玻璃参数（blur 值、saturate、透明度、边框、高光）；浅色 / 深色下壳上文字均清晰；内容区素面、无玻璃材质；滑杆两端实测通过；玻璃栏下方滚动内容经过时栏内图标文字仍可辨认。
