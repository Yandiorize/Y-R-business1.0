# 顶栏两处改动：图标按钮换样式 + 计时器去嵌套

> 只改这两处的外观，不要动任何功能：三个按钮的功能、计时逻辑、交卷逻辑全部照旧。
> 背景：顶栏三个细线圆圈图标按钮反复修不好（先是椭圆，现在是细线淡圈、图标小而难认），不再继续修圆圈，直接换一种样式。

## 1. 三个图标按钮换种样式（不再用细线圆圈）

- 放弃现在的“细线圆圈 + 纯图标”样式，改为“图标 + 文字”的小胶囊按钮，三个分别是：🗑 清空、A 字号、🌙/☀️ 主题（文字写“主题”二字，不要只留图标让人猜）。
- 三个按钮统一样式、同高、同间距；图标与文字同色、对比度足够，在深色下清晰、在浅色下也清晰。
- 按钮宽度由内容（图标 + 文字）自然决定，不许再出现椭圆、细线淡圈、图标过小的问题；空间不足时标题文字省略号截断，不挤压按钮。
- 顶栏品牌 Y-IELTS、logo 图标不动。

## 2. 计时器取消“框里套框”

- 现状：阅读工具条是一个大圆角框，里面的计时器（60:00 + 进度条）又单独套了一个小圆角框，双层嵌套看着不自然。
- 改法：取消计时器内层的圆角边框——时间数字与进度条直接落在工具条上，只保留工具条外层一层框；交卷按钮保持独立按钮，不再被第二层框套住。
- 进度条与时间数字的对齐、颜色、计时功能全部不变。

## 自测与汇报

- 手机、桌面各一遍；浅色、深色各一遍：三个按钮是统一样式的图标 + 文字胶囊、清晰可认；计时区只有一层框，时间与进度条对齐自然。
- 三个按钮点一遍确认功能还在（清空弹确认、字号切换、主题切换）；计时与交卷正常。
- 最后只汇报改了哪个文件 + 自测结果 + 发布链接。
