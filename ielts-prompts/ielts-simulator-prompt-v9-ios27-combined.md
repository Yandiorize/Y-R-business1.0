## 本版必做 8 项（v8 原文并入，逐项验收）

### 1. 反馈卡片补例句

- 现状：练习页答错后反馈卡片有中文释义和“再听一遍”按钮、底部有已答统计，但反馈卡片里没有例句。
- 改法：答错后反馈卡片必须包含：中文释义 + 例句 + “再听一遍”按钮；例句只在答后出现，答前不剧透。
- 先查词条数据里有没有例句字段：有则渲染出来；如果该词条本身就没有例句数据，卡片不留空白位，在汇报里写明“该词条无例句数据”即可——**不许编造例句**。

### 2. 阅读容器宽度改到 96vw

- 现状：桌面端阅读容器只有约视口宽度的 82%，没达到 96vw + 12–16px 左右边距；两栏高度已顶满，不要动。
- 改法：内容容器宽度改为 96vw 以上、左右边距 12–16px；超宽屏可设 1600px 上限防止行过长；手机（≤430px）布局不动。

### 3. 发音状态提示 + 修“暂无可用语音”误报

- 现状（两处问题）：点喇叭确实能出声，但播放中没有任何文字状态，只靠按钮变蓝表示；设置区还挂着红字警告“当前设备暂无可用语音”，可实测明明能出声——语音可用性判断是错的。
- 改法：
  1. 播放状态必须有文字：播放中显示“播放中…”，失败显示“朗读失败，点我重试”，喇叭按钮始终可手动点；不许只用颜色变化表示状态；
  2. 语音可用性判断必须以 speechSynthesis.getVoices() 的实际结果 + voiceschanged 就绪为准：列表还在异步加载时不许提前下“无语音”结论；检测到有语音时，红字警告必须消失；真正无语音时才显示警告，并给出可操作提示；
  3. 重申禁令：发音链路（本地音频 → IndexedDB → 在线接口 → 系统 TTS）任何一级失败都必须有可见反馈，最终兜底必须走到系统 TTS 或明确提示无可用语音，不许静默没声。

### 4. 默写模式补发音入口

- 现状：拼写默写模式新题会自动读，但页面上只有输入框和提交按钮，没有重听按钮——听不清就没法重听，默写没法好好做。
- 改法：
  1. 默写页题目旁常驻一个大号喇叭按钮，可无限次手动重听；
  2. 再加一个“发音”开关：开 = 新题自动朗读，关 = 只手动点喇叭才读，默认开；
  3. 只读单词本身，不读词性、释义、标点；发音失败时按钮旁显示“朗读失败，点我重试”，不许静默没声。

### 5. 底部标签栏改矮、五个按钮稍大

- 现状：底部标签栏（阅读 / 听力 / 写作 / 单词 / 范文五个按钮）整体偏高，看着像一条厚“刘海”压在页面底部。
- 改法：
  1. 栏体改矮：压缩标签栏的上下内边距，整体高度缩短一档；
  2. 五个按钮同步稍大：图标与文字字号各放大一档（约 10%–15%），保持清晰可辨；
  3. 五个按钮等宽均匀分布，选中态样式不变；
- 约束：按钮触点不小于 40px；底部安全区 padding-bottom: env(safe-area-inset-bottom) 必须保留，不许 Home 指示条遮挡按钮；栏体改矮不许靠裁切图标或文字实现。

### 6–7. 液态玻璃：以 iOS 27 版为准（取代 v9 原 P-6、P-7 的数值）

## 一、iOS 27 标志功能：玻璃透明度滑杆（必做）

- 在主题设置区加一个“玻璃透明度”滑杆，连续可调：从“清晰”（接近实色）到“通透”（高度透明），默认停在中间档；
- 滑杆实时生效：拖动时全站玻璃透明度跟手变化（用 CSS 变量统一控制，如 --glass-opacity，铬层与容器层按比例联动）；
- 选择要记住：滑杆位置存 localStorage，刷新、切换主题后保持；
- 滑杆两端都要实测：拉到“清晰”端文字必须完全清晰可读，拉到“通透”端玻璃感必须明显（内容从下方透过来）。

## 二、默认渲染：高对比 + 更鲜艳（iOS 27 的默认取向）

- 默认档 = 中等透明度（铬层约 0.55、容器层约 0.75），不许默认就拉到最透；
- 默认渲染要比之前更鲜艳：玻璃层 saturate(1.4–1.8)，背景光斑色彩比之前浓一点，让玻璃看起来是“有颜色的光”，不是灰白雾；
- 文字对比优先：默认档下正文、题号、选项、按钮文字必须清晰可读——这是 iOS 27 精修要解决的核心问题，不许为了透牺牲默认档的可读性。

## 三、边缘：锐利分层 + 折射感（iOS 27 图标重绘的路子）

1. 边缘锐利：每层玻璃边缘清晰分明——1px 细边框 + 顶部 1–2px 高光边，不许边缘发虚、糊成一团；
2. 分层立体：图标、按钮、卡片做成多层结构——底色层 + 玻璃层 + 高光层，层与层之间有可见的分离（像 iOS 27 图标那种近 3D 的分层感），不许一层颜色糊到底；
3. 折射感：玻璃下的内容用 backdrop-filter: blur + 亮度/饱和微调模拟轻微折射；栏体、侧栏边缘的折射要延续到边缘（不许边缘处突然截断成实色）；
4. 图标保本色：图标颜色保持自身颜色，不许被下方背景透色带偏（iOS 27 侧栏图标就是修了这一点：图标保持本色、不洇到背景里）。

## 四、纵深分离：层与层一眼分开

- 背景、卡片、弹窗、悬浮栏之间用透明度差 + 模糊差拉开前后关系：背景最糊、卡片次之、弹窗与悬浮栏最实但仍透；
- 弹窗出现时，下方页面要有一层极淡的遮罩 + 模糊，让弹窗与页面一眼分开，不许弹窗和页面糊成一层；
- 栏体形态向 iOS 靠拢：顶栏、工具条、底部标签栏做成悬浮胶囊式——四周留边、大圆角、不贴边贴底，浮在内容之上（这是 iOS 液态玻璃的标志形态）；栏体已改矮、按钮已放大的要求同步保留。

## 五、深浅主题与动效

- 浅色：白底玻璃 + 深色字；深色：深底玻璃 + 近白字；滑杆位置在两套主题下都生效；
- 主题切换、滑杆拖动时玻璃参数平滑过渡约 200–300ms，不许生切；
- 按钮、选项悬停时透明度 +0.05–0.1、高光略亮，按下时透明度 −0.05；
- 遵守 prefers-reduced-motion：减动效模式下取消一切玻璃过渡与悬停光流动画。

## 六、可读性底线（iOS 27 精修的出发点，违反即为未完成）

1. 文字永远纯色，不许加透明度；长文区（阅读文章、范文正文、写作编辑区）容器透明度在默认档不低于 0.75；
2. 同一区域不许两层以上半透明叠加；
3. 玻璃栏下方滚动内容经过时，栏内图标文字仍可辨认；
4. 滑杆拉到“清晰”端时，全站必须回到接近实色、处处可读——这是给眼睛的兜底。

## D 部分：手机版专项（≤430px 宽度，桌面布局不要动，用媒体查询隔离）

1. 安全区：固定/吸顶顶栏加 padding-top: env(safe-area-inset-top)（constant() 兜底），底部标签栏加 padding-bottom: env(safe-area-inset-bottom)；不许写死像素值；灵动岛、刘海、Home 指示条都不能遮挡按钮；
2. 顶栏单行化：logo + 标题在左、按钮组在右，一行放完，不换行、不遮挡、不裁切（配合顶栏胶囊按钮）；
3. 全站禁止横向滚动：任何页面在 390px 宽下不得出现左右滑动，超宽元素自己内部处理，不许撑破页面；
4. 阅读：左右分栏改上下堆叠或“文章 / 题目”切换标签，不要把两栏硬挤在一起；计时器和交卷按钮始终可见可点；40 题题号格完整显示、每格可点；划词高亮工具条不超出屏幕边缘、不被吸顶顶栏盖住（位置做边界钳制）；
5. 写作：题目区、编辑区、统计面板上下堆叠；编辑区高度够打字，统计数字不挤成一团；工具条换行分组，但计时器、开始、交卷等关键按钮换行后仍完整可见；
6. 单词：卡片与按钮全宽排列，点击目标不小于 40px；导入文本框、筛选、列表、练习行在窄屏不溢出；
7. 范文：列表卡片单列，详情正文行宽适配手机，不用横向滚动；详情头按钮行换行；
8. 弹窗：一律居中、四周留边距，按钮可点，不许超屏；
9. 固定栏（顶栏 / 底部标签栏）不得遮挡正文内容：给页面加足上下滚动留白；
10. 手机端模块工具条取消吸顶或压成一行，只保留主顶栏吸顶（吸顶换行成 2–3 行会吃掉 200px 以上高度）。

### D-增补：实测量化清单（桌面端实测数字，换算到 390px 必然出问题，逐条达标才算过）

1. 顶栏单行内容总宽约 1260px，其中模块导航标签就超过 440px——手机上必须有移动端方案（导航进底部标签栏或横向滚动条），计时器、交卷、设置按钮不许被挤出屏幕；
2. 阅读题号格每格只有约 33×30px、角标小旗约 12px，远低于 40px 点击标准——手机端题号格放大到不小于 40×40（可减少每行列数或让题号区独立滚动），小旗热区同步放大；
3. 阅读左右两栏是固定高度、各自内部滚动——手机堆叠时不许保留双内滚：改成整页滚动，文章与题目自然衔接（或切换标签），不能出现两个小矮窗格；
4. 写作工具条单行约 1200px、单词练习行约 800px、范文详情头约 480px、词库工具行约 480px——手机上一律允许换行分组，但关键按钮换行后仍完整可见；
5. 确认弹窗桌面宽约 420px，比 390px 屏幕还宽——所有弹窗加 max-width: calc(100vw - 32px)，按钮高度保持 ≥44px；
6. 次要文字约 12px（题号数字、词数统计等）手机上偏小：手机端辅助文字不小于 12px 且保证对比度，正文维持约 15px 不动。

## E 部分：自查补缺（逐项先报状态：已有 / 半成品 / 没有，缺哪补哪）

1. 倒计时提醒：阅读剩余 10 分钟计时器变红轻微闪烁；剩余 1 分钟 toast 提示一次，不重复触发；
