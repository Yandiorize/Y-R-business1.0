## 第 0 部分：本版用户体验（必做）

### 0.1 起始页简约

- 起始页（审计确认：目前没有独立落地页，打开即阅读页；本项针对该首屏）只留核心内容：开始 / 继续练习 + 阅读 / 听力 / 写作 / 单词 / 范文模块入口；
- 去掉多余装饰与堆叠卡片，留白、层级清晰，一眼能找到入口；
- 从起始页到开始练单词、开始练阅读各不超过两次点击；
- 启动动画如有，保持短促、可跳过、不挡入口；
- 顶栏分层：logo、5 标签、数据按钮、计时、交卷、清空、字号、主题、滑杆挤在一行、中部标签重叠——分层或精简，不许标签重叠遮挡。

### 0.2 起始页与网页主题色同色

- 起始页背景与主色取当前主题色，与内页主题色同色，不许起始页一套色、内页另一套色；
- 浅色 / 深色切换时起始页同步变色；刷新后保持当前主题；
- 桌面端审计显示起始页已跟随主题；本项重点是窄屏 / 真机下同色对齐，浅色、深色各验一次；
- 验收：浅色、深色各看一次起始页与内页，颜色一致。

### 0.3 单词正误提示音大点

- 单词三模式（英译汉 / 汉译英 / 拼写默写）答对 / 答错提示音增益提高，外放与听筒下都清晰可闻；
- 答对 / 答错音色区分不变（答对清脆上扬、答错低沉短音），只提增益；
- 只提提示音增益，不动单词发音音量；不许失真 / 爆音；
- 目前提示音只有开关、没有音量调节；本项先提高默认增益，不新做音量滑杆；
- 验收：三模式各答对 / 答错一题，提示音清晰可闻且可区分。

### 0.4 声音控件名义统一

- 全站只留一个“发音”开关（新题自动朗读）；
- 口音选择器改名“口音”（选项美音 / 英音不变）；
- “提示音”开关名不变；三处控件名义不得重复；
- 验收：轮前面板只看到一个“发音”、一个“口音”、一个“提示音”。

### 0.5 误导文案清理

- 汉译英答后喇叭不得显示“当前设备暂无可用语音”当按钮名；语音不可用时显示真实状态（如“点喇叭重试”）或隐藏，不许把失败文案当按钮；
- 口音区附近残留的“当前设备暂无可用语音”字样清干净；
- 验收：汉译英答后喇叭正常显示“再听一遍”/ 朗读；口音区附近无红字误报。

### 0.6 听力失败状态的出路

- 听力播放失败时，除红色失败提示外，给出可用操作：有效的重试；如本地音频未配置，提示原因；
- 失败后按钮状态必须可用，不许失败后按钮全变“重播”且点按无声；
- 播放成功路径不受影响；
- 验收：复现失败路径时重试可点、状态变化；播放成功时按钮状态正常。

### 0.7 首屏不得是已交卷的禁用卷

- 如已有交卷记录，首屏默认显示可直接开始的新卷 / 继续入口，不许用户先看到一纸答案全禁用的已交卷空白卷、再自己找“重新作答”；
- “重新作答”放显眼处，一眼能找到；
- 验收：已有交卷记录时打开，首屏可直接开始练习，无需先找重新作答。

### 0.8 主题按钮文案

- 主题按钮是三段循环（浅色 / 深色 / 跟随系统），按钮应标明当前模式与下一点切换目标（或图标 + 当前模式），不许用户误读按钮为“切换到某模式”的动作；
- 验收：连点三次，模式按浅色 → 深色 → 跟随系统 → 浅色循环，每次按钮文案与实际模式一致。

### 0.9 空白卷标注

- 空白 / 未作答交卷的 Band 显示必须明确标注“空白卷 / 未作答”，不得让人误读为真实成绩；
- 验收：空白卷交卷结果页一眼能看到“空白卷 / 未作答”标注。

### 0.10 单词入口统一

- 开始复习 / 开始本轮 / 开始一轮练习 / 练错词四个开始类动作并存，定一个主入口，其余降为次要或合并，不许用户面对四个开始按钮不知道走哪条；
- 载入示例词表入口同页出现 3–4 次，留一处；
- 验收：单词页只有一个主开始入口、一个示例词表入口。
