# 7 天验证计划（宠物洗护模板包）

总原则：先验证有没有人愿意付，再考虑扩大。预算 100 元以内，不买广告、不先建复杂网站。

## 价格测试（不要同时挂三个价，先测一个）
- Day 1-2：先挂 29.9 元（中间价）
- 如果 2 天内 0 咨询：换 19.9 元再测 2 天
- 如果咨询多但不付：换 49.9 元测是不是价格问题，还是目录 / 信任问题
- 记录：每个价的浏览量、咨询量、付款量、退款量

## 每天做什么
- Day 1：发首帖（你自己手动发，选你最常用的 1 个已有账号/群）
- Day 2：私聊 3 个你认识的宠物店相关的人，问要不要先看目录
- Day 3：回所有咨询，先发目录，不直接催付
- Day 4：把咨询里最常问的 3 个问题补进 FAQ
- Day 5：复盘：哪个渠道来的咨询最多？哪个价格被问最多？
- Day 6：按复盘结果只留 1 个渠道 + 1 个价格再发一次
- Day 7：算账，决定继续 / 换价 / 停

## 验收标准（7 天结束时看）
- 成：至少 3 个人付款（不管是哪个价），且 0 退款纠纷
- 待定：有咨询没付款 → 问题在目录、信任或价格，改一处再测 3 天
- 停：7 天 0 咨询 → 不是价格问题，是渠道 / 人群不对，停下来换渠道，不要继续投钱

## 成本控制（100 元以内）
- 工具：0 元（手机日历 + 微信 + 现有账号）
- 广告：0 元
- 预留：100 元以内只用于必要的工具 / 打印 / 杂费，超了要先停下来复盘

## 合规红线（再说一遍）
- 不批量私信、不群发陌生人、不买客户名单
- 不收集宠物主人的身份证、住址等不必要信息
- 不复制竞品付费模板、商标、图片，全部是原创话术
- 不承诺治病、不承诺涨单、不承诺自动接入微信
- 关键动作（发帖、收款确认）都由你本人做

## 后端升级（只有模板包卖出去后才推）
- 模板包买家如果问“能不能帮我搭一套”：再推 599-999 元的客服分流搭建（1 渠道、标准化）
- 不要在首帖里同时卖模板包和搭建服务，先让模板包跑通
