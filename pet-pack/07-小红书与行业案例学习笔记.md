# 小红书与行业案例学习笔记 · 2026-10-22

先说一个实话：小红书帖子本身大多要登录才能看全文，这次网页搜索没有拿到小红书单篇帖子的原文，所以下面不是“我抄了某篇小红书帖子”，而是从能公开查到的行业报告、价目页、消费投诉案例里提炼的、可直接用到模板里的规律。没有编造小红书账号、点赞数、具体帖子内容。

## 1. 中国宠物主人怎么选店（KPMG 2025中国宠物行业报告，经公开报道）
- 2024年，80%以上宠物主人用抖音看宠物产品直播，淘宝68%、京东40%、拼多多30%、小红书30%；购物渠道上，天猫淘宝90%、京东60%、拼多多35%、抖音25%、小红书20%。
- 选品牌时最看重：性价比近60%、品牌可信度55%、品牌知名度40%、朋友推荐30%。
- 中国宠物产品市场预计2025年达到4840亿元。
- 对模板的启示：不要只写“便宜”，要写“这个价含什么、不含什么”，性价比要算得出来；朋友推荐要单独做一句话模板，因为30%的人靠推荐；小红书/抖音不是卖货主渠道，是种草和信任渠道，洗护前后对比、过程照片要先征得主人同意才能发。

## 2. 价目透明是行业最大投诉点
- 消费投诉案例里，宠物美容最常见的纠纷是“意料之外的费用”：体型大小各家标准不一、附加费差别大、套餐快过期约不上、退剩余款被拒。
- 台湾2025年推出的宠物美容标准合同也要求：必须事前 disclosed 价格、事前问清宠物是否有攻击性、约定超时取宠费用、商家有错3天内退款、预付套餐解约手续费有上限。
- 对模板的启示：报价不能只写“小型犬XX元起”，要写体重分档、短毛/长毛分档、洗澡和造型修剪分开、打结/厚毛/指甲等附加费事前确认。售前确认单是必补的模板，原60条里没有单独一张确认单。

## 3. 价目结构：分档 + 分层 + 单点附加
- 公开价目页的常见结构（以境外和港台店为例，价格数字不直接照搬到国内）：
  - 洗澡：按体重分档，如 <5kg、6-9kg、10-15kg、15-20kg，短毛和长毛分开。
  - 造型修剪：洗澡价 + 造型价，两档分开写。
  - 单点附加：剪指甲、去结、厚毛去毛、贵宾修剪等，单独标价，事前确认。
  - 基础套餐含：洗澡、吹干、梳理、剪指甲、清理耳朵外围、脚底毛、肛门腺等，列成清单打勾，而不是一句“基础服务”。
- 对模板的启示：把“洗护包括什么”从一句话改成可打勾的清单；把“多少钱”从一档改成体重+毛长两维分档。

## 4. 会员和复购是真收入来源，不是赠品
- 上海、广州的案例里，线上预约 + 会员计划做起来后，会员复购成为主要收入；反面案例是套餐约不上、快过期不提醒，最后闹到投诉。
- 对模板的启示：会员模板不能只写“充XX送XX”，要写有效期、到期前7天提醒、约不上时的替代时间、暂停/退卡计算规则。这几条原模板已有，这次在新增模板里把“约不上”单独成一条。

## 5. 宠物是家人，不是商品
- 国内报道里，25-35岁、受过高等教育的新一代宠物主人占近一半，把宠物当家人看，洗护一次约300元左右也愿意付，怕的是在家自己洗会伤到宝贝、怕店里硬做。
- 对模板的启示：语气不要写成“下单、发货、售后”，要写宝贝名、性格、怕什么、怎么安抚；怕生、紧张、老年、幼犬的模板要单独写，不能用同一句“没关系”打发。
