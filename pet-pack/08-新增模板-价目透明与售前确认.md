# 新增模板 · 价目透明与售前确认（10条，补原60条的缺口）

使用顺序：先发第1条确认单，再谈价格。所有 [ ] 换成自己店的实际信息再发。

1. 售前确认单（约好前发一次，客户回复“确认”才开始）
   跟您确认一下今天的服务：宝贝 [名字/品种/体重]，项目 [洗澡/造型修剪]，价格 [XX元]，含 [洗澡、吹干、梳理、剪指甲、清理耳朵外围、脚底毛、基础修剪]，不含 [造型附加/去结/厚毛处理，如有按第3条确认]。预计 [X小时]，[时间] 来接，超时取宠按 [规则] 算。您回复“确认”我就按这个做，做完不会中途加价。
2. 体重分档报价（不要只写大中小）
   我们按体重和毛长分档报：[短毛：<5kg XX元 / 6-9kg XX元 / 10-15kg XX元 / 15-20kg XX元；长毛：<5kg XX元 / 6-9kg XX元 / 10-15kg XX元 / 15-20kg XX元]。洗澡和造型修剪分开算，造型在洗澡价上加 [XX元]。您把宝贝体重大概发我，我按档报一个准确价。
3. 打结/厚毛附加费提前确认
   宝贝毛如果打结严重或毛特别厚，处理要多花时间，附加费是 [去结 XX元起 / 厚毛处理 XX元起]，开始前我会先拍照跟您确认要不要处理、处理到什么程度，确认后才动手，不会做完再收费。
4. 攻击性/紧张提前询问（开始前必问）
   宝贝平时怕生吗？有没有咬人、护食、特别怕吹风机或剪指甲的情况？有的话请提前告诉我，我会安排慢节奏、安静时间段，实在不配合会停下来联系您，不会硬做。
5. 预约满了的替代方案（不要只说约满了）
   您想约的 [日期 XX:XX] 已经满了，我看了一下，[同一天 XX:XX / 次日 XX:XX] 还有空，您看哪个方便？我先帮您留，约好后发您确认。如果两个都不行，您告诉我能来的时间段，我帮您排第一个空位。
6. 套餐快过期与延期规则
   您的套餐还有 [X次]，有效期到 [日期]，到期前7天我会提醒您一次。如果到期前实在约不上，请提前跟我说，我按 [延期规则] 帮您处理，不会让您过期了才发现用不了。
7. 洗护前后对比照片授权（发朋友圈/小红书前必问）
   今天洗护前后我拍了照片，您方便让我发到店里的朋友圈/小红书上吗？只发宝贝的照片，不发您的姓名和联系方式。您说可以我再发，您说不可以我就只发给您自己看。
8. 朋友推荐感谢（朋友来了之后发）
   谢谢您推荐 [朋友名] 来，朋友第一次按体验价 [XX元]，您下次来可以减 [XX元]，我已经帮您记下来了。下次来报您的名字就行，不用再发截图。
9. 服务后异常报告（店主发给主人，不是主人问才说）
   今天服务情况跟您同步一下：宝贝 [名字] 做了 [项目]，用了 [产品名]，过程中 [是否配合/有没有停下来休息]。回家后留意 [抓挠/红肿/精神]，有异常拍照发我，持续不舒服建议去兽医那里，我这边把今天的产品和过程记下来，方便兽医判断。
10. 退卡计算示例（不要只说按规则退）
    您卡里还剩 [X次]，单次价是 [XX元]，剩余金额是 [X × XX = XX元]，按规则 [能退/不能退的原因]，能退的话退 [XX元]，[X天内] 到账。我把计算过程发您看一下，您确认无误我再办。
