# Y 项目合集

本仓库由 Muse 部署，包含以下项目（2026-10-24）：

- tests/：趣味测试 5 站 — 恋爱 love-test-upgraded.html、金钱 side-hustle-test-customer.html、城市 city-test-customer.html、旺甘 wanggan-test-customer.html、哲学 historical-figure-test.html。邀请码每周一换，4位：首字母Y（大小写都行）+3位数字，例如本周 Y317，下周一换成 Y136；上周的码下周一自动失效。
- docs/：Y-STORE 与小红书商业化文档、商品展示页。
- yandi/：炎帝聚创策划与商标筛查。
- pet-pack/：宠物美容模板包（Y-STORE 首件商品资料）。
- ielts-prompts/：Y-IELTS 模拟器各版提示词与 super 计划（模拟器本体为 WorkBuddy 托管网页，不在此仓库）。

GitHub Pages 开启后，tests/ 下的 html 可直接用 github.io 地址打开。
