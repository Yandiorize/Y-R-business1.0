# 微店上架文案：4 站趣味测试完整版

价格先按：单站 0.99 元，四站通票 2.99 元（首发价）。
手工发货时先上 2 个商品就够了：单站商品让用户下单时备注站名，通票商品一次发 4 条完整版链接。
要自动发货就不能用这 2 个，必须拆成 5 个（见下面“自动发货”一节）：因为自动发货发的是每个商品固定写好的内容，它不会看备注帮你选站，备注选站的单站商品做不了自动发货。

上架前先在微店 App 里实测确认：0.99 元能不能设为售价；每单手续费和提现费是多少。没确认前不要说“到手就是 0.99 元”。

## 发货步骤（这个商品没有快递、没有文件、不用填地址）

发货 = 付款确认后，私信发完整版链接。没付款不发完整版链接，免费版链接可以先发。

1. 看订单：微店 App 里打开这单，确认状态是已付款，不是只下单未付款。再看备注：单站要的是哪一站，通票不用问站。
2. 没备注站名：先在微店私信或小红书私信问一句“你要哪一站”，不要猜，不要单站订单直接发 4 条。
3. 发链接：从你自己保存的未公开完整版清单里复制，不要手打，不要发免费版链接。单站发 1 条，通票发 4 条，每条前面写清站名。
4. 点发货：如果微店订单页有发货按钮，发出链接后再点；如果它要填快递单号，不要编一个假单号，先看商品是不是设成了虚拟商品/无需物流那档，实在没有这档就只用私信发货并留记录，不要硬填。
5. 记一笔：日期 / 订单号 / 站名 / 链接已发。链接打不开就重发一条对的；链接正常打开后，按商品页规则不支持退款。

## 自动发货（先在 App 里找这几个设置，找不到就先手工发）

先说实话：公开搜索没找到微店官方的自动发货教程，按钮名可能随版本和店铺类型变，下面是按虚拟商品的通用做法写的，App 里实际叫什么以你看到的为准。不要凭这段话在商品页写“自动发货”，要你自己在 App 里看到、并用 1 单测通了才算。

### 自动发货的核心改动：商品要拆成 5 个

- 恋爱完整版 0.99 元、自动发货内容 = 恋爱站完整版链接；
- 金钱完整版 0.99 元、自动发货内容 = 金钱站完整版链接；
- 旺甘完整版 0.99 元、自动发货内容 = 旺甘站完整版链接；
- 城市完整版 0.99 元、自动发货内容 = 城市站完整版链接；
- 四站通票 2.99 元、自动发货内容 = 4 条完整版链接。

不要再用“单站商品 + 备注选站”那 1 个商品做自动发货，系统发的是固定内容，不会读备注。

### 在微店 App 里这样找

1. 微店店长版 App → 商品管理 → 新建/编辑商品。
2. 商品类型选虚拟商品（如果只有实物/虚拟两档，选虚拟；如果没有虚拟这档，先停下来，不要硬用实物商品卖链接）。
3. 找发货方式 / 发货设置，选自动发货（有的版本叫自动发货、虚拟商品自动发货、发货内容）。
4. 在自动发货内容框里贴下面对应商品的文字，不要只贴一条裸链接，买家拿到裸链接容易以为是广告链接不点。
5. 运费 0 元，保存，上架。

>
> 提醒：这是娱乐趣味测试，仅供娱乐参考，不是心理测评。
> 链接打不开请在订单里联系我，我给你换一条；链接正常打开后，虚拟商品不支持退款。

> 谢谢下单！这是四站完整版链接，每站 1 条，打开直接做测试、看完整报告：
> 恋爱：[链接]
> 金钱：[链接]

> 城市：[链接]

> 提醒：这是娱乐趣味测试，仅供娱乐参考，不是心理测评。
> 链接打不开请在订单里联系我，我给你换一条；链接正常打开后，虚拟商品不支持退款。

### 自动发货后，你还要做的 2 件事

1. 买家付款后不用你再发链接，但买家是在微店订单里看到这段内容，不是小红书私信里自动收到。所以小红书私信和商品页要改一句话：付款后请在微店订单里查看完整版链接，不用等我私信。否则买家会以为还没发货，来催你。
2. 完整版链接一换（比如 WorkBuddy 重新发布），必须马上把 5 个商品的自动发货内容全换成新链接。旧链接失效了，自动发货还在发旧的，买家就会投诉链接打不开。

### 上线前必须用 1 单测通

不要直接拿真实买家当测试：
- 先设好 1 个站的自动发货内容，保存。
- 等第一单真实订单来，看买家是不是在微店订单里直接看到了链接；如果买家说没看到，马上手工补发同一条链接，不要让买家等。
- 如果 App 里根本找不到虚拟商品 / 自动发货这两个设置，说明你这个店铺版本或类型不支持，那就退回手工发货，不要在商品页写“自动发货”，也不要找第三方插件绕过去。

### 如果找不到自动发货：半自动退路

把上面私信模板存成手机快捷短语或微店快捷回复，订单通知一来就贴模板 + 复制链接发，1 单不到 1 分钟。0.99 元的单量没起来之前，半自动完全够用，不要为了自动发货去换平台或开新店。

## 上架后自查（发第一篇笔记前做完）

1. 标题、价格、运费 0 元、交付方式、退款规则、个人出品那行，6 项都在。
2. 商品详情里没有“99%准”“测过的都说准”“已卖多少单”这类话。
3. 商品图不用别人的照片，不用 WWR 图标，品牌名和图标定了再统一换。
4. 自己下一单测试流程走一遍：下单 → 备注站名 → 私信收到完整版链接 → 打开能做完 22 题 → 能看到完整报告。
5. 每天记 1 行：日期 / 微店订单数 / 完整版链接发出数 / 有没有链接打不开。
