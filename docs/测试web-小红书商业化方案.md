## 先说清一个关键点：不能真的“搬进”小红书

小红书不是网页托管平台，不能把 HTML 测试页上传进去，也不能在笔记里直接挂测试链接卖。

所以这套方案的真实结构是三件分工，不是一件搬家：

- **小红书 = 流量入口和信任入口**：只发笔记，不开店、不直播。
- **测试 Web = 产品本体**：继续留在海外静态托管（现在的 WorkBuddy 域名形式），不换 .cn/.com，不做 ICP，不在站内收款。
- **微店 = 收款和交付口**：用户在微店下单，你在微店/私信里发未公开的完整版链接，用户直接打开完整版做测试、看完整报告。

这正好沿用你之前定过的路线，不是新开一条线。

## 本方案沿用的既有约束（没改之前都算数）

1. 只用你已有的个人小红书号发笔记，**不做新的实名认证，不开小红书店铺，不开直播**。
2. 笔记正文和评论区**不放微信号、不放支付宝收款码、不放微店链接、不写“加微信付款”**。链接只在有人私信问的时候，在私信里发。
3. 一天最多 1 篇笔记，不连发，不刷量。
4. 不编造销量和评价，没有真实反馈就写“先看示例”。
5. 以个人出品算，不写“成都市炎帝聚创科技有限公司出品”——公司还没注册，不能这么写。
6. 测试 Web 不收集手机号、身份证，不做登录，答题数据只留本地浏览器。

如果你之后想改其中任何一条（比如愿意去开小红书店），那是第 3 阶段的可选项，不是本方案的默认项。

## 产品怎么切：免费引流，付费看完整版

不要一上来就全站收费，也不要全站免费。切成两层：

### 免费层（人人可玩，用来涨流量）

- 正常做完 22 题（以最终版为准，见“前置条件”）。
- 出 1 页简版结果 + 1 张可晒的结果卡。
- 简版结果只给类型名 + 一两句定性描述，不给完整分项解读。

### 付费层（微店下单，发完整版链接）

- 完整报告：全部结果分项、思维导图、详细解读、注意事项、长图版结果卡。
- 交付方式：微店下单后，你在微店/私信里发对应站的完整版链接（未公开，不发笔记、不发评论区、不放免费页）。
- 单站买 1 条链接，通票买 4 条链接。

### 定价已定：先按单站 0.99 元、四站通票 2.99 元卖

2026-10-24 定价走了三步：先是 9.9 / 29.9 元草稿，再是 0.99 / 1.99 元二选一（你先选了 1.99 元），最后你改成先按 0.99 元卖。2026-10-24 晚：历史站砍掉后，通票改为四站 2.99 元（单买 4 站合计 3.96 元，通票省 0.97 元）。“先”这个字是关键：0.99 元是首发价，不是永久价。

| 商品 | 首发价 | 说明 |
|---|---|---|
| 单站完整版 | 0.99 元 | 一块钱不到，先破零、先验证“有人愿意付费” |
| 四站通票 | 2.99 元 | 比单买 4 站（3.96 元）便宜 0.97 元，好推“一次买齐” |

先用 0.99 元的理由：首单最难，0.99 元几乎没有犹豫，最容易拿到第一笔付费和第一批晒图。代价也写清楚：交付现在是手工发链接，0.99 元的量上来后私信工作量会先于收入上来，100 单才 99 元，还没扣手续费。所以 0.99 元只跑首发验证期，7 天验证通过、且微店能设自动发货后，再谈涨回 1.99 元，不要长期用 0.99 元扛手工量。

上架前必须在微店 App 里实测确认两件事（不要凭记忆）：0.99 元能不能设为售价；每单的平台手续费和提现费是多少，扣完还剩多少。这两项没确认前，实际到手价不算数。

### 静态站的技术现实，要先认

现在的测试页是静态页，没有服务器校验订单。上一版写的“解锁码”有个致命问题：码表如果嵌进页面，任何人看源码就能拿到全部码，等于公开。所以 v1 改成未公开完整版链接：

- 免费页和完整页是同一套题目和计分，只差结果展示：免费页只出简版，完整页出完整报告；
- 完整版链接不放进免费页、不发笔记、不发评论区，只在付款后私信发；
- 链接被买家转分享的风险在 v1 依然防不住，这不是假装能防住的。应对办法是：
  1. 定价低，分享的动力本身就小；
  2. 结果卡上带测试站名和免责声明，不带用户隐私答案，分享出去也不暴露隐私；
  3. 手工记账每单发了哪条链接，发现某条链接被公开转发就停发该链接、换新链接给后续买家（已买的用户不受影响的前提是旧链接先不断，等新链接稳定后再处理）；
  4. 只有销量验证通过后，才值得升级到带服务器校验的版本（第 3 阶段再议）。

## 漏斗：用户实际会走的 5 步

```
小红书笔记（钩子 + 结果示例图）
  → 用户私信问“怎么测 / 完整版怎么买”
    → 私信里发：免费测试链接 + 完整版价格 + 微店链接
      → 用户先玩免费版，觉得准/有意思
        → 微店下单 0.99 元（单站）或 2.99 元（通票）
          → 你发完整版链接，用户直接打开完整版
            → 用户晒结果卡 → 回流到小红书（需经用户同意才转发）
```

关键细节：

- 私信不要一上来就只发微店链接。先给免费链接，让用户先玩，付费意愿是在免费结果出来那一刻最高的。
- 私信话术要固定模板，不要每单现编，也不要在私信里催单。
- 完整版链接发出后，用户打不开：包换、包退。链接已正常打开：虚拟商品，事前在微店写清“完整版链接发出后不支持退款”，不要事后扯皮。

## 小红书内容怎么做：先做 12 篇，1 天 1 篇

### 每篇笔记的固定结构（不要换结构，只换站和钩子）

1. 钩子：一个具体场景或一句好奇问题，不要写“99%准”。
2. 3 道题截图：只放题目，不放全部答案逻辑。
3. 结果示例图：用你自己的结果，或空白示例卡。不要用别人的结果截图，不要编“网友都说准”。
4. 结尾一句话：完整版私信问。不要写链接、微信、价格以外的收款方式。

### 4 站 × 3 个角度的选题表（第一批）

| 站 | 角度 1：场景钩子 | 角度 2：反差钩子 | 角度 3：结果晒图钩子 |
|---|---|---|---|
| 恋爱 | 吵架时你先冷静还是先说清楚？ | 测完发现自己不是想象中那型 | 我的结果卡长这样，你呢？ |
| 金钱 | 花钱前你先算账还是先开心？ | 存钱型和体验型吵起来是什么样 | 金钱观结果卡示例 |
| 旺甘 | 顺境时你靠什么稳住？ | 外人看你旺，实际消耗在哪 | 结果卡 + 一句解读示例 |
| 城市 | 你适合快节奏还是慢节奏城市？ | 喜欢的城市和适合的城市不一样 | 城市匹配结果卡示例 |

上面是选题方向，不是定稿标题。正式发之前，每篇标题和正文要再过一遍合规红线（下一节）。

### 发布节奏

- 第 1–7 天：每天 1 篇，先发恋爱、金钱、城市这 3 个最容易懂的站，轮着发。
- 第 7 天晚上复盘：够 3 单就继续；不够就先诊断，不加量、不开店。
- 第 8–12 天：补齐剩余角度，开始推四站通票 2.99 元。
- 用户晒图：只有用户自己发出来并同意，你才能转发或截图用。不要私自截私信里的结果图发笔记。

## 合规红线：这几条碰了就可能限流或封号

每篇笔记、每个测试页、每张结果卡都要同时满足：

1. **只写“娱乐趣味测试”，不写“心理测评”**。页脚和结果卡都要写：仅供娱乐参考，不是心理评估、不是诊断、不是医疗建议。
2. **不碰疾病和情绪诊断词**：不写抑郁、焦虑、人格障碍、你有 XX 症，也不写“测出你的心理问题”。
3. **不碰命理和运势预测**：金钱站写消费观/理财风格，不写财运、发财、破财；城市站写城市气质匹配，不写风水、宜居命。
4. **不承诺准确率**：不写“99%准”“测过的都说准”“科学验证”。
5. **不编造信任背书**：不写已卖多少单、多少人测过、客户评价，除非是真实、可查的数字。
6. **不站外引流硬推**：笔记和评论区不放链接、微信、收款码；不要批量私信陌生人，不要在评论区回复“私我发链接”刷屏。
7. **不用没授权的素材**：不用别人的照片、不用 WWR（War Robots）图标做测试站的商业标识——那个图标在 Y-STORE 是你单独定的例外，不要默认搬到测试站来。测试站的品牌名和图标要你另定。
8. **个人出品要写清**：微店商品页写“个人出品，非公司产品；炎帝聚创尚未注册”，和宠物包同一条 honesty line。

## 前置条件：先做完这 3 件，再发第一篇笔记

1. **先等测试最终版**：现在 4 站的 22 题转换与 bug 扫尾已做完，中间的 max-power 版你已定为不对外发。商业版必须基于最终版做，不要拿中间版去卖，否则用户付费买到的是会被改掉的版本。
2. **商业版要做 2 件事**（给 WorkBuddy 的任务清单，详见执行包）：
   - 免费/付费分层：公开免费版只出简版 + 分享卡；另做一套未公开完整版，题目和计分不变，只把完整报告全部放开；
   - 结果卡和页脚免责声明：每张卡、每个结果页都带“仅供娱乐参考”一行字。
   - 注意：只加分层和卡，不改题目、不改计分、不改已验证的题目逻辑；不要做解锁码输入框。
3. **微店先上架、完整版链接先备好**：
   - 微店商品名示例：单站“XX 测试·完整版”、通票“四站测试·完整版通票”。
   - 商品页写清：价格、交付方式（下单后私信发完整版链接）、虚拟商品退款规则（链接打不开包换包退，已正常打开不支持退款）、个人出品 honesty line。
   - 完整版链接先在手机上实测打开一遍，确认题目、计分、完整报告都正常，再上架。

## 手工运营表：每天记 5 个数就够了

不用上统计 SDK，静态站也统计不了。每天记：

| 日期 | 笔记标题 | 私信问的人数 | 免费玩完的人数（私信反馈估算） | 微店订单数 | 完整版链接发出数 |
|---|---|---|---|---|---|
| | | | | | |

复盘只看一个转化链：笔记 → 私信 → 免费玩 → 下单 → 发完整版链接。哪一步掉得最多，就改哪一步，不要全盘重做。

## 7 天验证标准：和宠物包同一条规则

- **7 天内付费 ≥ 3 单：通过**，继续做完 12 篇，推通票。
- **7 天内付费 0–2 单：不通过**，先停下来诊断 1 天，再决定改钩子、改价还是改免费/付费切分。不要直接加量、不要直接开店、不要换平台。
- 诊断顺序：先看私信量（没人问 = 钩子/标题问题），再看免费玩完率（玩了不买 = 完整版吸引力不够），最后看价格（问了价不买 = 0.99 元仍高或交付不信任，0.99 元已经是底价，再降空间不大，那时先改免费/付费切分和交付信任，不要再降价）。

## 第 3 阶段（可选，默认不做）：小红书店

只有在同时满足下面两个条件时，才值得讨论开店：

1. 7 天验证通过，且 30 天内稳定出单；
2. 你愿意做一次新的身份认证。

开店的现实情况（以 App 内实际页面为准，公开指南的说法仅供参考，未在你账号实测前不算定论）：

- 个人店据公开指南称一般需要一定粉丝量和身份认证，有的说法是 1000 粉 + 身份认证；企业店需要营业执照等资料和认证费。
- 开店的好处是站内可直接下单、信任度高；代价是你要交资料、走审核、受平台交易规则和售后规则约束，和现在“笔记 + 微店”的轻模式完全不同。
- 所以开店不是“升级”，是换模式。要你明确点头才启动，不要因为一两篇笔记爆了就冲动开店。

## 附录 A：如果主线其实是 Y-IELTS，方案要改的地方

1. **版权关口先过**：现在模拟器里有剑桥 17 Test 1 的内容，商业化不能直接卖含真题的版本。必须先换成原创模拟题，或只卖原创的规划/复习工具部分，且不能打“官方”“真题”旗号。
2. **价格不能套测试站的价**：IELTS 是备考工具，不是冲动型趣味测试。它的买断价和更新包价格你之前还没定，这两个价要单独定，不能照搬测试站的 0.99 元。
3. **流量打法也不同**：小红书笔记要从“测测你是哪型”换成“模拟流程、计时规则、错题复盘怎么做”，受众是备考人群，不是泛娱乐人群。
4. **结论**：Y-IELTS 如果要商业化，先做“去真题 + 定价”两步，再谈小红书。不要和 4 站趣味测试共用同一套微店商品和同一批笔记。
